# 数据源侦察结论（公开渠道 · 公办院校 + 题库）

> **产出**：team-lead ｜ **日期**：2026-10-12
> **背景**：用户要求「题库我自己搞定（从互联网/公开平台获取）」「学校数据从各院校官网获取并筛选出**公办**学校数据」。
> **原则**：只用**公开合法渠道**；标注可验证性；不编造。

## 一、公办院校数据源（权威性分级）

| 级别 | 来源 | 能拿到什么 | 可用性 |
| :-- | :-- | :-- | :-- |
| ⭐⭐⭐ 权威 | **教育部直属院校名单**（各省教育厅官网转载，如北京市教委 `jw.beijing.gov.cn`） | 学校代码 / 学校名称 / 办学类型 / **举办者（中央/地方）** / **性质** / 地址 / 邮编 | ✅ 页面为静态 HTML，可直接解析 |
| ⭐⭐⭐ 权威 | **双一流建设高校名单**（含学校代码） | 147 所双一流高校名称 + 学校代码 | ✅ 公开名单，结构规整 |
| ⭐⭐⭐ 权威 | **研招网招生单位代码**（`yz.chsi.com.cn`） | 招生单位代码 / 名称 / 所在省市 | ⚠️ 目录查询接口需登录 cookie；首页与名单页可访问 |
| ⭐⭐ 参考 | 第三方汇总（如 `fapingedu.com` 转载的研招网数据） | 省份 / 是否自划线 / 是否博士点 / 是否双一流 | 🔶 仅作交叉校验，不作唯一来源 |
| ⭐⭐ 参考 | **freecho/yzw**（GitHub，MIT） | 研招网硕士专业目录全量（学校/专业/招生人数/考试科目/学校层级）**14 万行现成数据** | ⚠️ release 的 33MB CSV 直连被断，需镜像或 git 克隆（项目含 `yzw.sql`） |

### "公办"判定依据
- **举办者 = 中央/地方教育部门**（非民办/非中外合作）→ 公办
- 交叉校验：军队院校（国防大学等，代码 92000+）单列；民办高校（举办者为"民办"或个人）排除
- 现有真库 `kaoyan_schools` 493 所的 `level` 字段（985/211/双一流/双非/一本）**已 100% 填充**，可作为底层分类

## 二、题库数据源（公开合法）

| 类型 | 来源 | 说明 | 可用性 |
| :-- | :-- | :-- | :-- |
| **复试机试真题** | CSDN 博客（0854 复试机试题集）、GitCode 开源仓库（如 `u014339447/pgcode` 收录多校机试真题） | 西电、浙大等院校机试题目 + 输入输出样例 + 题解 | ✅ 公开可读，需逐题整理 |
| **考研真题** | 用户本地 `knowledge_base`（已 5010 文件）+ 百度网盘 `/考研` | 各科真题 PDF（含官方答案） | ✅ 已有 |
| 编程练习 | LeetCode / 洛谷 等公开题库 | ⚠️ **有版权，不能直接爬取入库**；可参考题目**类型**自行出题 | ❌ 不入库原文 |
| 复试面试题 | 人人文库等文档站 | 计算机复试面试题（编程/算法/OS/网络） | 🔶 需人工整理，注意来源标注 |

### 版权红线（必须遵守）
1. **力扣等商业题库有版权** → 不直接爬取原文入库；只抄"题目类型与交互范式"，自行出题或用公开复试真题。
2. **公开复试机试真题**（各校公布/经验贴整理）→ 可用，但需标注来源。
3. AI 生成的题必须标 `ai_generated` + 人工确认后才进正式题库（沿用项目 `answer_source` 先例）。
