## 三、本轮代码改动（仅 `spider_notices.py`）

| 函数/常量 | 改动 | 作用 |
|---|---|---|
| `UA` | 补 `Accept` / `Accept-Language` / `Accept-Encoding` | 提升反爬 WAF 放行率（对北邮/安大 412 仍无效，如实记录） |
| `_fetch` | 读取原始 bytes，按 `Content-Type` + `<meta charset>` 自动解码（`_decode`），兼容 GBK/GB2312 | **通用修复**：解救所有 gb2312 老站（天大等） |
| `_LINK_RE` | 锚文本由 `([^<]{2,120})` 改为 `(.*?)` + 剥标签 | **通用修复**：解救 `<a>` 内套 `<font>` 的站（东北大学等） |
| `_strip_tags` | 新增：先剥 HTML 注释再剥标签 | 防注释残片（`-->`）混入标题 |
| `_SECTION_KW` | 白名单由 6 词扩至 ~20 词（研究生招生/研招/招生管理/硕士公告/通知通告…） | 解救首页栏目名不在原白名单的站（贵师/贵财等） |
| `_NAV_EXACT` | 新增：纯导航短词集合，在 `parse_notice_links` 中排除 | 减少「硕士招生」等栏目名被当公告的噪声 |
| `KNOWN_SECTION_URLS` | 新增：4 站已验证的列表页直达 URL（天大/北科大/华科光电/东北） | 首页 JS 导航站兜底 |
| `_collect_notices` | 抽出为独立函数：webplus→HTML→栏目跟进(2 层)→已知列表页兜底→保序去重 | 结构清晰、可复用、可测 |
| `crawl_school_notices` | 调用 `_collect_notices(..., school=name)` | 传递站名以启用 `KNOWN_SECTION_URLS` |
| 映射表 | 北科大 URL 校正为 `yzxc.ustb.edu.cn`（原 `yjsy.ustb.edu.cn` 302→登录页） | 修正失效入口 |

## 六、失败原因分类（修复后）

- **A. 环境不可达（13）** —— 非域名/解析器问题，**需生产环境复测**
  - 502 Tunnel（8）：浙大/杭电/长春理工/西南交大/武大/武理/哈工程/遵义医科 —— 沙箱代理出网受限
  - HTTP412（2）：北邮/安大 —— 反爬 WAF，需更完整浏览器指纹或改用其子域
  - HTTP403.6（1）：浙工大 —— 服务端 IP/地域限制
  - SSL 被拦（1）：云南大学
  - 读超时（1）：贵州民族大学
- **B. 解析 0 条（1，技术边界）**
  - 中国科学技术大学：纯 JS 渲染，正文在 `onclick="window.open('/article/...')"`、标题分散于 div；
    实现中曾试 JS-onclick 提取，但标题噪声大（会误抓导航文本），**按「不硬啃」原则回退并如实标记**。

## 七、下一步建议

1. **生产环境复测**：在能直连 `*.edu.cn` 的服务器重跑，预计可达率显著提升（13 个不可达多为环境噪声）。
2. **中科大专项**：需 headless 浏览器（Playwright）或破解其栏目接口；成本高，暂列 P2。
3. **反爬站**（北邮/安大/浙工大）：补 Referer/完整指纹，或走研招网聚合页兜底。
4. **数据质量**：`_NAV_EXACT` 已过滤栏目导航噪声；建议入库前再按 `infer_notice_type` 做类型强过滤。
