## 3. 政治栏真相

- 814 题中：**真政治（含马原/毛中特/思修/史纲术语）仅 5 题**。
- 381 题与其它电子题一同被关键词判据命中（模电/数电）。
- 178 题含 ≥1 个电子术语但未达阈值；250 题**无任何领域信号**（OCR 碎片/答案串，
  如"3V，锗管为"、"× 93.√"）。
- 抽样 18 条剩余政治题：全部是场效应管/差动放大/数字电路/非门/稳压电源 等电子内容。
- **剩余 33 题的来源同样非政治**：管综真题(17)、法硕真题(8)、考研答题卡(5)、历史学(2)、真题(1)。

**结论：`政治` 科目当前几乎不存在真实政治题。** 该栏不是"部分脏"，而是整体性错误。

## 4. 根因分析

### 4.1 直接原因：文档入库时被错误标注为"政治"
`documents` 表中，3 个《【电子技术基础】国家职业资格培训》文档的 `subject` 均为 `政治`：

```
('【电子技术基础】国家职业资格培训.txt', '政治')
('【电子技术基础】国家职业资格培训.pdf', '政治')
('【电子技术基础】国家职业资格培训.pdf', '政治')
```

题库导入（qbank/ingest 流程）直接继承了文档的 `subject`，于是这 781 道题全部落到"政治"。

### 4.2 分类器本身的问题（已部分修，但仍留缺口）
`services/kb_service.py` 的 `classify_subject_confidence()` 对文件名打分定科，实测：

```python
classify_subject_confidence('【电子技术基础】国家职业资格培训.txt', '')
# 当前返回：('其他', False)
```

即**当前版本**的分类器不会把该文件判成"政治"——它会落到低置信兜底 `其他`。
说明这条"政治"标注是**历史遗留**（更早版本的分类器/默认值产生的），当前分类器已改进。

**但缺口仍在**：分类器对"【电子技术基础】"这种**无"数字/模拟"限定的电子资料**
无法定科（`_SUBJECT_STRONG` 里"模拟电子技术"需要"模拟电子/电子线路"等词，
裸"电子技术"不命中；也没有 `电子技术基础` 这一专名）。因此即使今天重导，
它也只会得到 `其他/真题综合`，**不会得到正确的"模电"**。

### 4.3 数据层面的系统性风险
- `documents.subject` 与 `quiz_questions.subject` **存在同源错误**，修 quiz 未修 doc；
  若不修 doc，重新导入会**再次引入**同样的错配。
- 其它非政治来源（管综/法硕/历史学真题、答题卡）也被归到"政治"，说明
  **兜底分类逻辑**可能把某些形态误判为政治（或历史批次写错）。

## 5. 建议

### 5.1 立刻可做（低风险）
1. **同步修正 `documents.subject`**：对同样 3 个文档改 `模拟电子技术`，
   否则重新入库会重现错配（**建议下一步做，属独立小任务**）。
2. **`pending_review` 125 条人工抽验**后决定是否补修（模电↔数电边界题）。
3. **加一个"科目兜底守护"**：入库时若分类器低置信，**不要默认写入某具体科目**，
   应写 `其他` 并打 `needs_review` 标记，避免"政治"这类误挂再次发生。

### 5.2 中期
4. 在 `_SUBJECT_STRONG["模拟电子技术"]` 增补专名 `电子技术基础`、`国职`、
   `康华光`(已有) 等，覆盖"无数字/模拟限定"的电子资料。
5. 政治题库**需真实题源补齐**；当前政治栏无可用于"按知识点刷题/薄弱点分析"的数据。

### 5.3 与 M1-1 的关系
- 本次纠错对**知识点关联覆盖率提升有限**（估算仅 +41 条）——瓶颈仍是
  **45.4% 题目缺 chapter**，而非科目。
- 但纠错对**归类正确性、按科目统计、薄弱点分析**是必要的。
- 知识点关联的真正瓶颈是 chapter 缺失 + OCR 碎片，需独立治理（清碎片、补 chapter）。
