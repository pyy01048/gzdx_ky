export function useLocalStorage(key, defaultValue) {
  const [value, setValue] = useState(() => {
    try { return JSON.parse(localStorage.getItem(key)) ?? defaultValue }
    catch { return defaultValue }
  })
  useEffect(() => {

  }, [key, value])
  return [value, setValue]
}

### 优点 1：专业课本位——电路图/波形/公式是"一等公民"

**为什么对你成立**：
通用考研平台（kaoyan.cn、考研帮、考研团）做不了电路图深解析，因为它们的用户是几百个专业的混合群体——给一个学法学的用户弹电路图识别功能是反体验。**而你只服务数电/模电考生**，电路图识别、波形分析、公式 LaTeX 化就是你的护城河，用户 100% 需要这个能力。

**具体做法（详细到模块）**：

1. **电路图识别管线**（已有基础）：
   - 上传/截图 → 调用 `services/circuit_vision.py` 检测元件（R/C/Q/Op-Amp 位号）
   - `services/circuit_analysis.py` 推理网表结构（节点、支路、连接关系）
   - LLM 结构化输出：`{components: [...], nodes: [...], topology: 'common_emitter'}`
   - 前端 `Assistant.jsx` 加"📷 拍题"按钮，触发整个管线

2. **波形分析**：
   - OCR 后波形区域用 OpenCV 分段识别（方波/三角/正弦）
   - 标注时间常数 τ、幅度 V_pp、周期 T
   - 结合题目讲"为什么是积分波形——因为 RC 时间常数远大于周期"

3. **公式 LaTeX 化**：
   - OCR 后公式区域用 KaTeX 渲染（`react-katex`）
   - 可点击查看"每一步推导"——展开为分步推导卡片

4. **解题输出标准格式**：
   ```
   ①图识别结果：[元件清单]
   ②考点：[静态工作点计算]
   ③公式：$I_B = \frac{V_{CC} - V_{BE}}{R_B}$
   ④数值：$I_B = \frac{12 - 0.7}{470k} = 24\mu A$
   ⑤答案：选 C
   ⑥引用出处：贵大 2023 年 834 真题.pdf 第 3 页
   ```

**验收标准**：
- 上传一道含三极管放大电路的题，**10 秒内**输出上述 6 段
- 错误率 < 10%（与人工对照 100 道题）
- 至少支持 5 种电路拓扑：共射/共基/共集/差分/OTL

**当前差距**：★★（满分 5）—— `circuit_analysis.py` + `circuit_vision.py` 已存在但**未端到端打通到 AI 助手前端**；Assistant.jsx 未集成"上传图片"入口。

**代码层落地路径**：

### 优点 2：学习闭环——但闭环的"节拍器"是 834 知识点树

**为什么对你成立**：

**具体做法（详细到表/接口）**：

2. **掌握度三态计算**（见 1.5.1）：
   ```python
   def kp_mastery(kp_id, user_id):
       total = count_questions_for_kp(kp_id)
       if total == 0: return 'no_questions', 0
       attempted = count_attempts(kp_id, user_id)
       if attempted == 0: return 'unlearned', 0  # 灰色，不进薄弱
       correct = count_correct(kp_id, user_id)
       rate = correct / attempted
       if rate >= 0.8: return 'mastered', rate  # 绿
       if rate >= 0.5: return 'reviewing', rate  # 黄
       return 'weak', rate  # 红
   ```

3. **薄弱知识点自动生成"今日补强计划"**：
   - 每天 6:00 跑 `services/scheduler.py` 扫描薄弱知识点

   - 推送到 `/api/tasks` 的今日任务

4. **复习调度按知识点**：
   - 错题表 `error_records` 加 `kp_ids` 字段
   - `review_scheduler.py` 按 kp_id 调度：今天复习"三极管放大电路"知识点下所有错题
   - 复习单元是"知识点卡片 + 代表题"，不是裸题

5. **变式题生成**：
   - 错题做对 1 次后，AI 生成同知识点变式题（同电路结构不同数值）
   - 加到 `quiz_questions` 表，source='ai_variant'

**验收标准**：

### 优点 8（新增）：内容层清洁——"数据可信"比"功能多"更重要

**为什么对你成立**：
19 号报告 8 个问题里 5 个是"内容层脏"（OCR 脏/口径矛盾/调度失效/角标死数字/掌握度全 0）。**用户对平台的信任来自内容层稳定，不是功能层数量**——你做 100 个功能但题库脏、口径矛盾，用户仍觉得"问题太多"。

**具体做法（详细到清洗 gate）**：

1. **OCR 导入预清洗 gate**：
   ```python
   # services/ingest_precheck.py
   AD_PATTERNS = [
       r'公众号[:：]?\s*[\u4e00-\u9fa5]+',
       r'微信[:：]?\s*[a-zA-Z0-9]+',
       r'考研专家|考研糖|研池大叔|水木观畴|东坡哥',
       r'第\s*\d+\s*页\s*\(OCR\)',
       r'高清视频课程',
       r'电子与通信工程考研',  # 水印
   ]
   def ad_gate(text):
       for p in AD_PATTERNS:
           if re.search(p, text):
               return False, f'命中广告模式: {p}'
       return True, ''
   ```

2. **数据口径标注**：
   - 每个统计接口响应里带 `caliber` 字段
   - 例：`{total: 9171, with_answer: 5525, with_analysis: 3402, caliber: '全库 / 有答案 / 有解析'}`

3. **调度参数定期校验**：
   - 每天跑 `scripts/check_scheduling_health.py`
   - "今日待复习" = 总数时告警
   - 掌握度全 0 时告警

4. **掌握度三态**（见 1.5.1）

5. **角标去死数字**：
   - 999+ 改为精确数 + 滚动加载
   - 或后端限制未读阈值（>100 时只显示 99+）

6. **全库脏数据清洗**：
   - 跑 `scripts/clean_quiz_draft_marks.py`
   - 跑 `scripts/clean_garbage_ai_answers.py`
   - 跑 `scripts/clean_junk_chunks.py`
   - 跑 `scripts/clean_notices_noise.py`
   - 全部跑完后 `SELECT COUNT(*) FROM quiz_questions WHERE content LIKE '%公众号%'` = 0

7. **数据质量监控页**：
   - `/quality` 页已存在（QualityDashboard.jsx）
   - 加"脏数据扫描"模块：每周扫一次全库，列出脏数据计数

**验收标准**：
- 题库 0 条含水印/广告/页眉
- 同一数字（题数/复习数）在任何页面口径一致
