## 第一篇 · 项目介绍（每一部分都要有）

### 1. 项目定位与目标

| 项 | 内容 |
| :--- | :--- |
| 项目名称 | 考研答疑自主学习系统（本地化考研学习平台） |
| 核心目标 | 面向**贵州大学 834 电子技术基础**（数字电子技术+模拟电子技术）考研备考 |
| 平台性质 | 答疑 + 自主学习 + 刷题 + 测试评分 + 院校数据分析 + 学习记录 **多功能一体** |
| 使用方式 | 个人单机为主；局域网良好时可推送到手机/平板；后续可能开源 |
| 核心原则 | **数据不出网**（本地模型 + 本地知识库），需要更强能力时可选云端 API 兜底 |
| 主要注重 | 答疑 + 自主学习 + 刷题 + 测试评分（用户原话） |

### 2. 技术栈

| 层 | 技术 |
| :--- | :--- |
| 后端 | FastAPI · SQLAlchemy 2.0 · SQLite（单文件 280MB）· APScheduler · uvicorn |
| 前端 | React 18 · Vite 5 · Zustand · React Router（HashRouter）· ECharts |
| 检索 | SQLite FTS5 + jieba（BM25）· 向量 KNN（bge-small-zh-v1.5）· RRF 融合 · LLM/bge 重排 |
| OCR | RapidOCR（PP-OCRv4 ONNX）+ pypdfium2；可选 PaddleOCR 微服务（端口 8888） |
| 本地模型 | Ollama（qwen3:8b / qwen3:4b / deepseek-r1:7b / qwen2.5vl:7b / qwen2.5:1.5b 等，按科目自动路由） |
| 微调 | Qwen2.5-3B + LoRA（peft/trl，可选）；SFT 样本 4670 条 |
| 网盘 | 百度网盘开放平台（OAuth + 自动续期） |
