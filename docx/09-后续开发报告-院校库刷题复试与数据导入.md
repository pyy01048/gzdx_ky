### 0.2 「历年分数同比批注」**当前数据做不出来**

你点名要"对比去年的在后面批注"。我查了真实数据：

```
kaoyan_scorelines 年份分布：
  2022: 5 行   2023: 5 行   2024: 5 行   2025: 7 行   2026: 788 行
同一 (学校,专业) 有 ≥2 年数据的组合：仅 5 个

```

**788/810 全是 2026 年一年**。只有 5 所学校有跨年数据，且 5 个组合的年份并不连续。

**结论**：同比批注**不是前端没做，是数据不存在**。要做得先补历史年份数据（见第七节数据导入链路）。
**在补数据之前，任何"同比"都是编的** —— 建议先做「年份切换」+「数据缺失明确提示」，等比注数据到位再上箭头。

### 4.2 力扣式编程题库（**工程量最大，建议单独立项**）

**必须新建的完整链路**：

```
表：problems           （题号/标题/难度/描述/约束/来源/语言支持）
    problem_testcases  （输入/期望输出/是否样例）

      GET  /api/problems            列表（难度/标签/来源/语言/我的状态）
      GET  /api/problems/{id}       详情（描述/示例/约束）
      POST /api/problems/{id}/run   试运行（样例用例）
      POST /api/problems/{id}/submit 正式提交（全量用例）
      GET  /api/submissions         我的提交记录

判题：services/judge_service.py
      · 语言：C++ / Python / C / Java（用户点名四种）
```
