## 二、为什么"功能太简单"——核心诊断

功能数量不少，但**体验层次**停留在"能用"而非"好用"，三个根因：

1. **信息架构偏"工具堆砌"**：30 个模块并列在侧边栏，缺少"今天该做什么"的引导层——用户打开首页不知道该练错题还是刷套卷还是背单词。
2. **数据有量但没"活"起来**：9171 题、1846 文档、493 院校都在库里，但**没有把数据加工成决策**——没有"你薄弱的知识点是 X、建议练 Y 组题"这种闭环。
3. **千行级巨石文件**（9 个）导致迭代变慢：改一处牵连一片，AI 续写上下文不够，功能只能小步修修补补，不敢做结构性增强。

> 结论：功能提升的重点不是"再加 10 个按钮"，而是**把已有数据变成学习闭环 + 补 3~4 个高价值新能力**。

## 三、功能提升方案（按价值排序，可落地）

### P0 级 · 让现有功能"闭环"（不新增模块，改造体验，1~2 天/项）

**F1. 首页"今日学习"引导层**（提升感知最明显）
- 首页顶部：今日目标（练 N 题 / 背 N 词 / 复习 N 错题）+ 一键开始按钮
- 数据源：学习计划 + 错题本 + 单词复习，全部是已有数据，只加一个聚合接口 + 首页组件
- 效果：打开就知道该干什么，不再面对 30 个平级入口

**F2. 刷题智能组卷**
- 按薄弱知识点自动组卷：错题本/做题记录 → 聚合错误率最高的 3~5 个知识点 → 从题库抽取对应题目生成 20 题组卷
- 支持"薄弱点优先""真题优先""随机"三种模式
- 数据已齐（错题本 + 知识点关联 kp_links 6288 条），纯增量接口

**F3. 错题复习计划推送**
- 艾宾浩斯时间点（当日/3 天/7 天/15 天）自动把到期错题聚合成"复习清单"
- 结合 F1 首页展示，复习完自动移出队列并记录二次正确率

**F4. 学习周报**
- 每周一生成：刷题量/正确率趋势/薄弱知识点变化/错题复做通过率/学习时长
- 一份可读的报告，用户能直观看到"这周进步在哪"

### P1 级 · 补高价值新能力（2~3 天/项）

**F5. 院校录取概率可视化**（择校核心价值）
- 用已有 810 条分数线 + 832 条招生数据：输入预估分 → 输出冲/稳/保三档院校列表 + 每个院校的录取概率区间
- 远程 adbafc3 已有"冲稳保自动调整"基础，合入后增强为可视化（概率条 + 雷达图对比）

**F6. AI 助教多轮上下文记忆**
- 同一会话连续追问可记住前文（当前 Agentic 状态机已有基础，补会话级记忆持久化）
- 支持"把这道错题讲给我听"→ AI 自动关联错题 + 知识库 + 给出解题步骤

**F7. 真题整卷模拟考试模式**
- 一键进入"2023 年真题卷"：倒计时 + 答题卡 + 交卷自动判分 + 成绩与知识点掌握度报告
- 数据已齐（真题 3008 题 / 79 套卷），缺的是"整卷模式"入口

**F8. 单词智能复习**
- 按遗忘曲线安排每日 30 词 + 听写模式 + 错误词自动进明日清单

### P2 级 · 体验与工程（治理先行，见 05 报告）

**F9. 依赖升级**：fastapi 0.104→最新稳定 + numpy/pydantic 升级 + 全量回归
**F10. 前端 e2e 补齐**：Playwright 覆盖刷题/择校/AI 三条主链路
**F11. 移动端体验**：底部导航 + 触控优化（现有布局桌面优先）
**F12. 暗色模式**：CSS 变量化（themeTokens.js 已有基础）
