## 一、架构层问题（高优先级）

### 1. University 模型设计严重不足
- **问题**：models.py 的 University 表用单个 JSON 字段 score_lines 存历年分数线，无法按年份/科目做结构化查询，数据库索引完全用不上。
- **影响**：做"2024 vs 2025 分数趋势"等分析需全表读出后在应用层解析 JSON，性能极差。
- **修复**：已新增 kaoyan_scorelines 表（year/total_line/politics_line/... 独立列 + 复合索引）。原 University 表应逐步迁移数据后废弃。

### 2. 前端路由扁平化，无模块化拆分
- **问题**：App.jsx 把 22+ 个路由全部平铺，没有嵌套/按模块分组。
- **影响**：首屏加载包含所有页面 chunk 引用。
- **修复**：用 React.lazy + 嵌套路由按模块分组，或用 Vite 的 import() 动态加载路由模块。

### 3. 图表能力不足
- **问题**：Charts.jsx 自实现 5 个 SVG 图表，无交互（tooltip/缩放/联动），做不了多系列折线/散点/箱线图。
- **修复**：已引入 ECharts（echarts ^5.5.0），封装为 EChart.jsx。

---

## 二、数据层问题（中优先级）

### 4. 知识库数据缺口大
- **问题**：真题答案覆盖率 15%（293/1869），解析仅 10 条；4,853/25,152 分块缺向量；知识点仅覆盖数电模电（其余14科为0）。
- **影响**：AI 答疑和知识检索在非数电模电科目上完全不可用。
- **修复**：需批量补充真题答案/解析 + 对空章节做知识点结构化 + 跑 kb_pipeline --heal --embeddings 补齐向量。

### 5. 学科体系封闭
- **问题**：taxonomy.py 硬编码 16 个科目，CORE_SUBJECTS 只含数电模电等，不支持电气/光学/计算机等学科。
- **修复**：已新增 kaoyan_subjects 表支持 8 个工科学科。后续应在 taxonomy.py 中扩展 EXT_SUBJECTS。

### 6. 数据库并发能力
- **问题**：SQLite 单文件数据库，写入并发能力有限。
- **修复**：个人使用够用；大规模爬虫写入建议在低峰期运行或考虑 PostgreSQL。

---

## 三、安全 / 工程问题

### 7. 前端 API client 无统一错误处理
- **问题**：新加的 kaoyanApi.js 自包含 request()（因为 client.js 的 request 是内部函数未导出），导致两套请求逻辑。
- **修复**：应将 client.js 的 request 导出为具名导出，所有 API client 统一引用。

### 8. ECharts 包体积过大
- **问题**：echarts 全量引入导致 EChart chunk 达 1MB+。
- **修复**：改用 echarts/core 按需引入（echarts/use 注册需要的图表类型），可减至约 300KB。

### 9. 缺乏前端自动化测试
- **问题**：后端有 128 项单测，前端 0 项。
- **修复**：至少对核心页面做 smoke test（Vitest + Testing Library）。

### 10. 爬虫合规性未声明
- **问题**：研招网爬虫未检查 robots.txt，无请求频率限制策略文档。
- **修复**：研招网 robots.txt 已 Allow: /，但应加明确延迟策略（2-5s）和断点续爬记录。

## 四、技术方向改进建议

### A. 数据采集体系化
1. 研招网爬虫（spider_yz.py 已有骨架）：定期爬取院校库 + 专业目录 + 招生人数
2. 院校官网爬虫：针对重点院校研究生院官网，自动解析复试线/拟录取名单 PDF
3. CSV 导入（import_csv.py 已有）：用户手动补充各校数据
4. txkyer 种子（seed_txkyer.py 已有）：222 校初始数据
5. 数据版本管理：按年份存储，支持历史对比和趋势分析

### B. 智能择校算法增强
- 当前 recommend 接口只做分数线匹配（score >= total_line）
- 应加入：复录比排序、录取均分匹配、专业方向匹配、区域偏好权重
- 可选：接入 AI 助手做自然语言择校问答

### C. 学科扩展路线
- 已支持：光学工程(0803)、电气工程(0808)、电子科学与技术(0809)、信息与通信工程(0810)、控制(0811)、计算机(0812)、软件工程(0835)、电子信息专硕(0854)
- 后续：按学科爬取研招网招生目录，丰富各学科院校数据

### D. 可视化增强
- 已引入 ECharts，后续可做：
  - 区域择校地图（中国地图热力图）
  - 院校 PK 雷达图（已实现骨架）
  - 分数线多年趋势（已实现骨架）
  - 招生人数分布散点图

### E. 与平台深度集成
- 当前择校模块是独立的 7 个页面
- 后续可与平台现有模块联动：
  - 择校结果 -> Goal 表（目标院校）
  - 院校专业方向 -> taxonomy 科目体系
  - AI 助手 -> 择校问答
  - 学习计划 -> 按目标院校分数线设定分科目标
