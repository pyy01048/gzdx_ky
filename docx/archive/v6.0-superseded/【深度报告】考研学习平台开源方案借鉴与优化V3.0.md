### 3.9 RAG/知识库类（7个项目）

| 项目 | 核心优势 | 可借鉴点 |
|------|----------|----------|
| **edu-rag** | 教育RAG框架：FastAPI+LangGraph+Milvus+BM25+RRF+CrossEncoder重排+检索门控+复杂问题分解+RAGAS评估 | **RAG质量提升全套方案** |
| **SCSE** | 计算机课程RAG | 课程知识库 |
| **AIChatbot** | AI聊天机器人 | 对话系统 |
| **internal-kb-agent** | 内部知识库Agent | 企业知识库 |
| **RAG-based-AI-Course** | RAG AI课程 | 教育RAG |
| **classroom-assistant-skill** | 课堂助手技能 | 课堂场景 |
| **reading-locator** | 阅读定位 | 文献定位 |

**edu-rag核心技术拆解**：
1. **意图分类**：教育问题→RAG，非教育问题→闲聊
2. **多策略召回**：direct / multi_query / decomposition（复杂问题拆子问题）
3. **混合检索**：Milvus COSINE稠密 + BM25稀疏 + RRF融合
4. **CrossEncoder重排**：BAAI/bge-reranker-base，懒加载
5. **检索门控**：top1分数<阈值→拒答/重试，低质量不进入LLM
6. **复杂问题深度路径**：分解→子问题独立检索→子答案并行生成→合成最终答案
7. **重试机制**：query variants / HyDE / Step-Back，最多2次
8. **RAGAS评估**：答案质量评估 + 检索评估（Recall@5/10/20, Precision@5, MRR@10, nDCG@10）

**与现有平台对比**：现有平台有FTS5+向量混合检索，但缺少：
- CrossEncoder重排（关键！直接影响检索精度）
- 检索门控（可能返回不相关结果）
- 复杂问题分解（长问题/多问处理差）
- RAGAS质量评估（无法量化检索质量）

#### 4.1.1 引入CrossEncoder重排

```python
# services/reranker.py（新建）
from sentence_transformers import CrossEncoder

class Reranker:
    def __init__(self):
        self.model = None  # 懒加载
    
    def _load(self):
        if self.model is None:
            self.model = CrossEncoder('BAAI/bge-reranker-base')
    
    def rerank(self, query: str, docs: List[Dict], top_k: int = 6) -> List[Dict]:
        """对检索结果进行重排"""
        self._load()
        pairs = [(query, doc['content']) for doc in docs]
        scores = self.model.predict(pairs)
        for doc, score in zip(docs, scores):
            doc['rerank_score'] = float(score)
        return sorted(docs, key=lambda x: -x['rerank_score'])[:top_k]
```

**落地步骤**：
1. 安装 sentence-transformers（`pip install sentence-transformers`）
2. 新建 `services/reranker.py`，懒加载CrossEncoder模型
3. 修改 `search_service.hybrid_search`，在RRF融合后增加重排环节
4. 修改 `ai_service.search_knowledge_base_hybrid`，调用重排器

#### 4.1.2 检索质量门控

```python
# services/retrieval_gate.py（新建）
class RetrievalGate:
    THRESHOLDS = {
        'simple': {'top1_accept': 0.60, 'relevant': 0.50},
        'medium': {'top1_accept': 0.60, 'relevant': 0.50},
        'complex': {'top1_accept': 0.45, 'relevant': 0.35},
    }
    
    def check(self, query: str, reranked_docs: List[Dict], complexity: str = 'medium') -> str:
        """返回 accept / retry / abstain"""
        if not reranked_docs:
            return 'retry'
        top1_score = reranked_docs[0].get('rerank_score', 0)
        threshold = self.THRESHOLDS.get(complexity, self.THRESHOLDS['medium'])
        if top1_score >= threshold['top1_accept']:
            return 'accept'
        if top1_score >= threshold['relevant'] * 0.6:
            return 'retry'
        return 'abstain'
```

## 九、风险与注意事项

### 9.1 技术风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| CrossEncoder模型大（~1GB） | 内存占用增加 | 懒加载，仅在检索时加载 |

| 风险 | 影响 | 缓解措施 |
