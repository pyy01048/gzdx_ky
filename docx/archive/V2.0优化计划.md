## 一、V2.0 核心目标

V1.0 完成了双项目融合，具备基础的学习平台功能。V2.0 目标是**深度优化学习体验，增强AI能力，完善测评体系**，从"能用"升级到"好用"。

### 核心提升维度

| 维度 | V1.0 现状 | V2.0 目标 |
|------|----------|----------|
| OCR识别 | RapidOCR（精度一般） | PaddleOCR PP-OCRv5（高精度，独立微服务） |
| AI能力 | 基础对话+RAG | 错题分析、考点诊断、作文评分、变式题生成 |
| 学习分析 | 简单统计 | 学习轨迹、薄弱考点、效率评估、成长体系 |
| 测评系统 | 基础刷题 | 测评答题成长系统、智能评分、学习报告 |
| 部署体验 | 单服务启动 | 多服务管理、一键启动、健康检查 |
| 质量保证 | 无 | QA测试体系、Bug追踪、回归验证 |

## 二、架构升级

### 2.1 多服务架构

```
用户浏览器
    │
    ├── 主服务 (FastAPI, 端口8000)
    │   ├── 业务API（学习/刷题/错题/计划）
    │   ├── AI对话+RAG检索
    │   └── 静态页面托管
    │
    └── OCR微服务 (FastAPI, 端口8888) ← 新增
        ├── PaddleOCR PP-OCRv5 模型
        ├── 图片/PDF文字识别
        └── 公式/手写识别（后续扩展）
```

### 2.2 数据层增强

新增数据表：
- `learning_traces` - 学习轨迹记录（每日学习时长、知识点覆盖）
- `weak_points` - 薄弱考点诊断（考点、错误次数、掌握度）
- `essay_grades` - 作文评分记录（题目、评分、维度分析）
- `study_reports` - 学习报告（周报/月报、趋势分析）
- `ocr_tasks` - OCR任务记录（异步任务、状态、结果）

## 三、功能模块详细规划

### 3.1 OCR升级（P0，最高优先级）

**参考项目**：PaddleOCRFastAPI2

**实现方案**：
1. 创建独立OCR微服务目录 `backend-ocr-paddle/`
2. 集成PaddleOCR PP-OCRv5模型
3. 提供REST API：POST /ocr（图片/PDF上传，返回识别结果+标注图像）
4. 主服务通过HTTP调用OCR微服务，保持解耦
5. 支持异步OCR任务（大文件/PDF多页）

**接口设计**：
```
POST http://127.0.0.1:8888/ocr
Content-Type: multipart/form-data
参数：file (图片/PDF文件)
返回：{
  "result": ["识别文字行1", "识别文字行2", ...],
  "detail_time": 1.234,
  "image_list": ["base64标注图像1", ...],
  "error": null
}
```

### 3.2 AI能力增强（P0）

#### 3.2.1 错题AI分析
- 自动分析错误原因（概念不清/计算失误/审题错误/方法不当）
- 生成详细解析和知识点链接
- 推荐同类变式题练习
- API：POST /api/errors/{id}/ai-analyze

#### 3.2.2 考点诊断
- 基于答题记录分析各考点掌握度
- 识别薄弱考点和高频错误
- 生成针对性复习建议
- API：GET /api/diagnosis/weak-points

#### 3.2.3 学习轨迹
- 记录每日学习时长、完成任务数、刷题量
- 生成学习热力图和趋势图
- API：GET /api/traces/daily

#### 3.2.4 作文/主观题评分
- 多维度评分（内容/结构/语言/书写）
- 智能评语和改进建议
- 参考qdpz-uniapp的作文测评功能
- API：POST /api/ai/grade-essay

### 3.3 前端新页面（P1）

#### 3.3.1 学习分析中心（/analytics）
- 学习时长统计（日/周/月）
- 各科目学习占比饼图
- 刷题量和正确率趋势
- 薄弱考点雷达图
- 连续学习打卡天数

#### 3.3.2 考点诊断（/diagnosis）
- 各考点掌握度进度条
- 薄弱考点TOP10列表
- 错误原因分布饼图
- 针对性复习建议

#### 3.3.3 测评成长系统（/assessment）
- 参考qdpz-uniapp的测评答题成长系统
- 闯关式答题（每个考点一个关卡）
- 星级评价和积分奖励
- 成长树可视化（答对题目浇水，知识点成长）
- 学习成就徽章系统

#### 3.3.4 学习报告（/reports）
- 周报/月报自动生成
- 学习效率评估
- 进步趋势分析
- 下周学习建议

### 3.4 现有功能优化（P1）

#### 3.4.1 刷题体验优化
- 答题后即时解析（AI生成）
- 错题自动收录和标签
- 收藏题目和笔记功能
- 刷题模式选择（顺序/随机/错题重练）

#### 3.4.2 AI对话增强
- 支持上传图片提问（OCR+AI）
- 对话历史持久化
- 引用来源可点击跳转
- 支持语音输入（后续扩展）

#### 3.4.3 知识库优化
- 文档上传进度显示
- 支持文件夹分类
- 文档内搜索高亮
- 基于文档出题功能

### 3.5 部署和启动优化（P1）

#### 3.5.1 增强版start.bat
- 自动检测Python环境
- 自动安装依赖（主服务+OCR服务）
- 多服务顺序启动（OCR服务→主服务）
- 端口占用检测和自动处理
- 健康检查等待
- 自动打开浏览器

#### 3.5.2 服务管理
- 统一的服务状态页面
- 各服务健康检查API
- 日志查看和下载
- 一键重启服务

## 四、QA质量保证体系

### 4.1 测试范围
- 功能测试：所有API接口和前端页面
- 回归测试：V1.0已有功能验证
- 性能测试：OCR识别速度、AI响应时间、检索效率
- 兼容性测试：Chrome/Edge浏览器、不同分辨率

### 4.2 测试用例设计
- P0核心流程：启动→配置AI→上传文档→AI对话→刷题→错题分析
- P1重要功能：学习分析、考点诊断、测评系统、OCR识别
- P2体验优化：页面交互、响应式、错误提示

### 4.3 Bug管理
- 严重程度：S1（阻断）/S2（严重）/S3（一般）/S4（轻微）
- 优先级：P0（立即修复）/P1（本周修复）/P2（后续迭代）
- 回归验证：修复后必须重新验证
