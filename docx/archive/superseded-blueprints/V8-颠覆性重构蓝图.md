# 考研学习平台 · 颠覆性重构蓝图（V8）

> 用户已授权「颠覆性重写」。本蓝图是执行权威依据，三支柱协同推进，
> 目标是把这个项目从"拼凑的演示级"提升到"像样的产品级"。

---

## 一、为什么必须重构（已核实的事实，不是猜测）

| 现状问题 | 事实依据 |
| :--- | :--- |
| 科目体系写死，用户不能自加 | `services/taxonomy.py` 的 CORE/MAJOR/EXT 是硬编码数组；`routers/taxonomy.py` 只有知识点 CRUD，无科目增删改接口；前端刷题/错题/题库/分项四页各自硬编码科目 |
| 知识库识别到题目几乎没有 | `quiz_questions` 1871 题**全部来源都是「真题:xxx」**，无一来自知识库文档自动提取；`qbank_builder.py`（文档→题库识别引擎）只在导入真题时用，从未在知识库全库跑过 |
| 前端是拼凑的，非一套体系 | `global.css:1-5` 注释写"暖纸墨蓝学术风"，实际生效的却是 v2 亮蓝冷调（代码与意图脱节）；993 处内联样式；空/载/错三态不齐；控制面板与展示面板视觉不专业 |
| 三处科目口径不一致 | 后端科目是"数字电子技术/模拟电子技术/数学/英语/政治/专业课"，前端写死的是"math/english/politics/major" |

## 二、设计方向（MainAgent 拍板）

**视觉定位：现代专业工具风（SaaS 级质感）**
- 主色：沉稳学术蓝（`#2B5A9E` 系），辅助色灰蓝
- 背景：浅灰（`#F5F7FA`）+ 白色卡片，干净不花哨
- 字体：现代无衬线系统字体栈，层级分明
- 布局：统一侧边导航 + 面包屑 + 卡片化内容区 + 一致的分页/表格/表单
- 数据可视化：统一图表风格（仪表盘、知识地图）
- **三态完备**：每个列表/数据区都有 加载中 / 空状态 / 错误态
- 彻底统一：**一套 CSS 设计令牌（variables）**，删除双体系冲突，收敛内联样式

## 三、三支柱执行阶段（有依赖，顺序不可乱）

### 阶段 0 · 设计系统建立（所有页面改造的基础）
- 统一 `:root` 设计令牌（颜色/字体/间距/圆角/阴影/层级 z-index 常量）
- 明确"暖纸墨蓝"或"亮蓝冷调"之争：**以现代专业工具风为准**，重写 global.css 头部注释与冲突令牌
- 建立基础组件规范（按钮/卡片/表格/表单/弹窗/空态/加载态/错误态），收敛关键内联样式
- 目标：新增页面与改造页面有同一质感，为后续阶段打底

### 阶段 1 · 科目体系可扩展化（用户最核心诉求）
- **后端**：科目从"代码硬编码"升级为"内置默认 + 用户自定义"双层
  - `taxonomy.py` 保留内置默认；`subject_config` 支持任意自定义科目名（不止预设池）
  - `routers/taxonomy.py` 或新路由新增**科目管理接口**：列科目 / 新增自定义科目 / 重命名 / 删除 / 为科目配置章节与题型
  - 确认 `normalize_subject` 对自定义科目保留原值（不误归一化到默认池）
- **前端**：新增**科目管理界面**（列表 + 添加 + 编辑 + 删除，可配章节/题型）
- **全站接入**：刷题中心 / 分项刷题 / 题库管理 / 错题本 / 知识库 的科目来源统一从后端 `/api/taxonomy/subjects`（或新接口）动态加载，彻底移除各自硬编码

### 阶段 2 · 控制面板与展示面板重做（用户强诉求）
- **仪表盘（Dashboard）重做**：清晰信息层级、专业统计卡、倒计时/进度/趋势可视化、今日任务
- **知识地图（KbMap）重做**：章节→知识点→题型三级结构的专业呈现，掌握度可视化
- 学习模块核心展示页（分项刷题、错题本、题库管理）套用阶段 0 设计系统
- 空/载/错三态在全部学习页补全

### 阶段 3 · 知识库 ↔ 刷题打通（让识别真正生效）
- 用现有 `qbank_builder.py` 在知识库 `documents` 全库批量跑，识别文档内题目（填空/选择/判断/简答/计算）
- 提供**预览确认界面**：识别出的题目先展示供用户勾选确认，再入库（避免误入库）
- 打通"文档 → 知识点 → 题目 → 错题 → 复习"闭环
- 入库时带 `source` 标注（如 `知识库:文档名`），可溯源

## 四、硬约束

- **不动现有正常功能**：刷题判定、错题闭环、AI 答疑、OCR、复习调度保持可用；改造是增强与统一，不是推倒重来
- **数据安全**：科目表化/迁移前备份数据库；知识库识别入库前先预览确认，不批量覆盖既有题
- **每阶段验证**：后端 pytest 全绿、前端 build + vitest 通过；控制/展示页用无头 Chrome 真实渲染截图取证
- **改动不 git 提交**（与 V7/V7.2 一起，等用户最终确认后统一固化）
- 语言：简体中文；代码注释、界面文案保持一致的专业水准
