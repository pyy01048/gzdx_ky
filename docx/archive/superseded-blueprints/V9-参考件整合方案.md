# 考研平台 · 参考件整合方案（V9）

> 用户提供两个网上参考前端，要求据此重做「刷题」与「院校数据」两部分，
> 后端对接我方 FastAPI，**风格统一为 V8 现代专业工具风**，并保留/补齐我方有、参考没有的功能。

## 参考件归属
- `D:\桌面\1` = **刷题训练**（Next.js16 + React19 + Tailwind4 + shadcn，纯选择题）
- `D:\桌面\zip` = **院校数据**（同上 + recharts，40 所电子信息类院校示例）

## 技术移植口径（重要）
- 我方前端是 **React18 + Vite + 普通 CSS（非 Tailwind）+ echarts（非 recharts）**
- 参考的 Tailwind class → **重写为我方 CSS（学术蓝设计令牌）**，不得引入 Tailwind
- 参考的 recharts → **改为 echarts**（沿用我方现有图表封装与配色）
- 参考用 lucide-react 图标；我方若无则统一用现有图标方案（如确需可评估引入 lucide-react，但风格须统一）
- 只移植**交互逻辑与信息架构**，视觉全部按 V8 设计系统重做

# 一、刷题模块（参考 `1`）

## 吸收参考的交互亮点
1. **首页 Hero + 统计带**：题库总量 / 已完成 / 正确率 / 错题数
2. **三入口 Tab**：按知识点 / 按年份 / 错题与收藏
3. **练习视图右侧答题卡**：网格显示每题状态（正确/错误/未做），点击跳转
4. **先选后提交**：选项先标记 draft，点「提交」才判分揭示（而非点选即判）
5. **练习 / 背题双模式**：背题模式直接显示答案与解析
6. **键盘快捷键**：A–F 选项、Enter 提交/下一题、← → 切换
7. **收藏题目**（星标）
8. **知识点视图**：左侧科目导航（含完成进度）+ 右侧知识点列表（题数 / 考频年数 / 完成进度 / 正确率 / 开始·继续·再刷）
9. **年份视图**：按年份卡片组织真题
10. **结果报告**：正确率大字 + 知识点掌握逐条进度 + 重练错题 / 再练一次 / 返回

## 对接我方后端
- 题目列表：`GET /api/quiz/questions`（支持 subject/chapter/difficulty/question_type/分页）
- 提交判分：`POST /api/quiz/submit`（答错自动写错题）
- 科目：`GET /api/taxonomy/subjects`（动态，含用户自定义）
- 知识点树：`GET /api/taxonomy/tree`
- 错题：`/api/errors/*`；收藏若无后端接口可先本地持久化（评估是否加 favorites 字段）

## 必须保留/补齐（我方有、参考没有）
- **多题型**：参考只做单选；我方须支持 单选 / 多选 / 判断 / 填空 / 简答 / 计算 / 作图（非选择题用「显示答案/解析」折叠 + 文本作答对照，不硬套 radio）
- **错题闭环**：自动入错题本、AI 分析错因、OCR 收录、艾宾浩斯复习调度
- **AI 答疑入口**：题目旁可「问 AI」
- **科目可扩展**：科目动态加载，不写死
- **题库管理 CRUD**：添加 / 编辑 / 删除题目（题库管理页保持）
