## 一、V2.0 核心升级

V2.0 在 V1.0 基础上，重点升级了 **OCR识别精度**、**AI学习分析能力** 和 **多服务架构**，从"基础学习平台"升级为"智能学习助手"。

### 升级总览

| 维度 | V1.0 | V2.0 |
|------|------|------|
| OCR识别 | RapidOCR（PP-OCRv4 ONNX） | PaddleOCR PP-OCRv5（独立微服务，精度更高） |
| AI能力 | 基础对话+RAG检索 | 错题分析、考点诊断、学习轨迹、作文评分、学习报告 |
| 架构 | 单服务 | 主服务 + OCR微服务（可独立扩展） |
| 学习分析 | 简单统计 | 薄弱考点诊断、错误分类、连续学习追踪、周/月报告 |
| 部署 | 单服务启动 | 多服务一键启动，可选OCR微服务 |
| API接口 | 60+ | 70+（新增6个学习分析接口） |

## 二、新增功能详解

### 2.1 PaddleOCR PP-OCRv5 高精度OCR微服务

**参考项目**：[PaddleOCRFastAPI2](https://github.com/tgtgwin/PaddleOCRFastAPI2)

**新增目录**：`backend-ocr-paddle/`

**特性**：
- ✅ 使用2025年5月发布的 PP-OCRv5 最新模型，识别精度和速度均有提升
- ✅ 支持中英文混合识别
- ✅ 支持图片格式：JPEG、PNG、BMP、WEBP、TIFF
- ✅ 支持 PDF 文件（逐页识别，最多10页）
- ✅ 返回识别文字 + 标注图像（识别框可视化）
- ✅ 批量识别（最多10张图片）
- ✅ 独立微服务，可单独部署和扩展
- ✅ REST API 接口，自动生成 Swagger 文档

**接口列表**：
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /health | 健康检查 |
| GET | /ocr/status | OCR模型加载状态 |
| POST | /ocr | 单文件识别（图片/PDF） |
| POST | /ocr/batch | 批量识别（最多10张） |

**主服务适配**：
- `services/ocr_service.py` 新增 `PaddleOCRService` 类
- 通过 HTTP 调用 OCR 微服务
- 微服务不可用时自动回退到本地 RapidOCR
- 支持健康检查和状态查询

**启动方式**：
```bash
# 方式一：V2.0一键启动（可选启动OCR服务）
双击 start-v2.bat

# 方式二：单独启动OCR微服务
cd backend-ocr-paddle
start.bat  # 或 python main.py
```

### 2.2 错题AI分析

**新增API**：`POST /api/analytics/errors/{error_id}/analyze`

**功能**：
- 自动分析错误根本原因（概念不清/计算失误/审题错误/方法不当/知识盲区）
- 生成详细解题步骤和思路解析
- 识别相关知识点（3-5个核心考点）
- 推荐2道同类型变式题练习
- 给出针对性复习建议和后续学习方向
- 自动更新错题记录的错误原因分类

**返回字段**：
```json
{
  "error_id": 1,
  "question": "题目内容",
  "user_answer": "用户答案",
  "correct_answer": "正确答案",
  "error_reason": "AI分析的错误原因",
  "error_category": "概念不清",
  "detailed_explanation": "详细解析",
  "related_knowledge": ["知识点1", "知识点2"],
  "similar_questions": ["变式题1", "变式题2"],
  "review_suggestion": "复习建议"
}
```

---

### 2.3 薄弱考点诊断

**新增API**：`GET /api/analytics/weak-points?subject=数学&limit=20`

**功能**：
- 基于答题记录和错题记录，分析各考点掌握度
- 识别薄弱考点TOP20（错误次数、掌握度、等级）
- 错误原因分类统计（概念不清/计算失误/审题错误/方法不当）
- 学科分布统计
- 每个薄弱考点给出针对性复习建议

**掌握度等级**：
- 🔴 薄弱（掌握度<40%）：建议重点复习
- 🟡 一般（掌握度40-70%）：建议定期复习
- 🟢 良好（掌握度>70%）：可适当减少复习

---

### 2.4 学习轨迹追踪

**新增API**：`GET /api/analytics/traces?days=30`

**功能**：
- 记录每日学习数据（完成任务数、刷题量、新增错题、学习时长）
- 连续学习天数统计（当前连续/最长连续）
- 学习日历热力图数据
- 周汇总数据（每周任务/刷题/学习时长）
- 总学习天数统计

**返回字段**：
```json
{
  "days": 30,
  "total_study_days": 15,
  "current_streak": 7,
  "longest_streak": 12,
  "total_tasks_completed": 45,
  "total_questions_done": 120,
  "total_study_minutes": 1800,
  "daily_data": [
    {"date": "2026-08-01", "tasks_completed": 3, "questions_done": 10, ...}
  ],
  "weekly_summary": [...]
}
```

---

### 2.5 学习报告生成

**新增API**：`POST /api/analytics/report`

**功能**：
- 自动生成周报/月报
- AI生成学习总结（鼓励性语气，300字以内）
- 汇总学习数据（学习天数、连续学习、任务完成、刷题量、学习时长）
- 薄弱考点分析
- 具体学习建议（基于数据生成，非空泛建议）

**报告类型**：
- `weekly`：周报（最近7天）
- `monthly`：月报（最近30天）

---

### 2.6 作文/主观题智能评分

**新增API**：`POST /api/analytics/grade-essay`

**功能**：
- 多维度智能评分（满分100分）
  - 内容切题（25分）
  - 结构逻辑（20分）
  - 语言表达（25分）
  - 词汇语法（20分）
  - 书写格式（10分）
- 亮点分析（2-3个作文亮点）
- 问题与改进建议（3-5个具体问题）
- 修改示范（选取1-2段文字给出修改版本）
- 总体评价（2-3句话总结）

**支持类型**：
- 英语作文
- 政治大题
- 专业课论述题
- 其他主观题

---

### 2.7 学习分析概览

**新增API**：`GET /api/analytics/overview`

**功能**：
- 汇总核心学习指标，用于Dashboard展示
- 当前连续学习天数、最长连续天数
- 本周任务完成数、刷题量、学习时长
- 正确率、总错题数
- TOP3薄弱考点
- 错误原因分类统计

## 三、架构升级

### 3.1 多服务架构

```
用户浏览器
    │
    ├── 主服务 (FastAPI, 端口8000)
    │   ├── 业务API（学习/刷题/错题/计划/知识库）
    │   ├── AI对话+RAG检索（FTS5+向量混合检索）
    │   ├── 学习分析API（错题分析/考点诊断/学习轨迹/作文评分）
    │   └── 静态页面托管
    │
    └── OCR微服务 (FastAPI, 端口8888) ← 新增
        ├── PaddleOCR PP-OCRv5 模型
        ├── 图片/PDF文字识别
        └── 批量识别 + 标注图像生成
```

### 3.2 服务间通信

- 主服务通过 HTTP 调用 OCR 微服务
- OCR 微服务不可用时自动回退到本地 RapidOCR
- 支持健康检查和状态查询
- 微服务可独立部署、独立扩展

## 六、启动方式

### 方式一：V2.0一键启动（推荐）
```bash
双击 start-v2.bat
```
脚本会询问是否启动PaddleOCR微服务，然后自动：
1. 检查Python环境
2. 可选启动PaddleOCR微服务（端口8888）
3. 安装主服务依赖
4. 启动主服务（端口8000）
5. 自动打开浏览器

### 方式二：仅启动主服务（V1.0兼容）
```bash
双击 start.bat
```
使用本地RapidOCR，不启动PaddleOCR微服务。

### 方式三：单独启动OCR微服务
```bash
cd backend-ocr-paddle
双击 start.bat  # 或 python main.py
```

### 方式四：手动启动
```bash
# 主服务
cd backend-main-fastapi
pip install -r requirements.txt
python -m uvicorn main:app --host 127.0.0.1 --port 8000

# OCR微服务（另开终端）
cd backend-ocr-paddle
pip install paddlepaddle paddleocr
python main.py
```

## 八、注意事项

1. **PaddleOCR首次启动**：会自动下载PP-OCRv5模型文件（约10-20MB），请确保网络畅通
2. **PaddlePaddle安装**：CPU版约500MB，首次安装较慢；如有NVIDIA显卡可安装GPU版提升速度
3. **PDF识别限制**：最多处理10页，避免大文件超时
4. **AI分析依赖**：错题分析、作文评分等功能需要配置AI服务商API Key
5. **数据兼容性**：V2.0完全兼容V1.0的数据库，无需迁移
6. **回退机制**：PaddleOCR微服务不可用时，主服务自动回退到本地RapidOCR
