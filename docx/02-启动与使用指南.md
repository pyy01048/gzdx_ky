# 02 · 启动与使用指南

## 一、环境要求

| 项 | 要求 | 本机实测 |
| :--- | :--- | :--- |
| Python | 3.10+ | 3.13.9（Anaconda `D:\Anaconda\python.exe`） |
| Node.js | 18+（**仅改前端时需要**） | v24 |
| GPU | 可选（本地模型加速） | RTX 4060 Laptop 8GB |
| Ollama | 可选（本地 AI） | 已装，用时打开即可 |

首次运行：

```bash
cd backend-main-fastapi
pip install -r requirements.txt
python scripts\diagnostics\check_env.py     # 环境自检（见下）
```

浏览器打开 **http://127.0.0.1:8000**（前端已构建在 `static/`，不改前端就无需 npm）。

---

## 二、5 种启动方式

### 方式 1：图形菜单（推荐）
双击 **`启动.bat`**：

```
[1] 本机模式     仅本机访问，最安全（日常推荐）
[2] 局域网模式   手机/平板可访问，显示二维码 + 自动放行防火墙
[3] 后台模式     静默启动（写 PID + 日志，便于精确停止）
[4] 停止服务     关闭正在运行的服务
[5] 打开浏览器   服务已运行时直接用
[6] 环境自检     检查 Python/依赖/数据库/前端/模型/端口
[7] 开发模式     前端热更新（需 Node.js）
[0] 退出
```

### 方式 2：单文件直启
| 文件 | 用途 |
| :--- | :--- |
| `启动-本机.bat` | 仅本机（HOST=127.0.0.1） |
| `启动-局域网.bat` | 手机可访问（HOST=0.0.0.0）+ 二维码 |
| `停止.bat` | 关闭服务（含后台模式） |

### 方式 3：命令行
```bash
cd backend-main-fastapi
python main.py                                             # 按 .env 的 HOST/PORT 启动
python run_server.py                                       # 后台模式（写 PID）
python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload   # 开发热重载
```

### 方式 4：前后端分离开发
```bash
# 终端1：后端热重载
cd backend-main-fastapi && python -m uvicorn main:app --reload
# 终端2：前端热更新（http://127.0.0.1:5173）
cd frontend && npm run dev
```

### 方式 5：桌面快捷方式
`python tools/create_shortcuts.py --all`（自动探测真实桌面路径，本机桌面被重定向到 `D:\桌面`）。

## 三、环境自检（重要）

```bash
cd backend-main-fastapi
python scripts\diagnostics\check_env.py
```

依次检查：Python 版本 → `.env` → 关键依赖 → **数据库（读 `DATABASE_PATH`）** →
Ollama 模型 → **前端构建产物 `static/index.html`** → 端口占用。

> 自检结尾会明确给出「✅ 没有阻断问题，可以启动」或「❌ N 个阻断问题」。
> 「Ollama 未启动」只是提醒（会走云端或跳过 AI），**不是阻断问题**。

## 四、手机 / 平板访问（局域网）

1. 双击 `启动-局域网.bat`（或 `启动.bat` 选 `[2]`），控制台打印地址与二维码。
2. 手机连**同一 WiFi**（别开流量），扫码或输入地址，如 `http://192.168.x.x:8000`。
3. **建议开启访问密码**：编辑 `backend-main-fastapi/.env` 设 `APP_PASSWORD=你的密码`，
   否则同一 WiFi 下任何设备都能访问。

手机打不开时排查：
- `.env` 里 `HOST=0.0.0.0`（局域网模式会自动设）
- 防火墙放行 8000（右键 `启动-局域网.bat` → 以管理员身份运行）
- 路由器关了 **AP 隔离**

手机端典型用法：拍照收录错题 → OCR 识别 → 挂靠知识点 → 加入复习队列。

## 五、本地模型与 AI 路由（可选）

### AI 路由模式（设置 → AI 服务，随时热切换）
| 模式 | 行为 |
| :--- | :--- |
| 自动（默认） | 学术/专业科目本地优先，文档/通用云端优先，失败互备 |
| 本地优先 | 本地失败自动转云端 |
| 云端优先 | 云端失败自动转本地 |
| 仅本地 | 禁用云端（数据不出网） |
| 仅云端 | 禁用本地 |

- 服务商（DeepSeek/豆包/通义/智谱/OpenAI 等）在设置页添加，**「测试接口」从服务端发起真实对话验证**；Key 存本机数据库、不回传前端、编辑留空=不变。
- 本地 Ollama 模型自动可用，无需添加。

### 电路读图题（AI 助手页 📷 按钮）
答疑输入区点「📷 图片」附加电路图/题目照片，发送后自动走智能路由的**电路分析分支**（qwen2.5vl 读图 + RapidOCR 标签 + 知识库检索）。VLM 读图较慢（数十秒到数分钟），回复会附推理链。批量答案回填运行期间 GPU 繁忙，读图会明显变慢或降级，回填结束后恢复正常。

### 目标院校可更换（设置 → 备考目标）
目标院校从院校库 493 所中选择（可搜索），也可手动输入；保存后同步写入后端目标档案（仪表盘倒计时、AI 画像、择校推荐共用）。

```bash
cd backend-main-fastapi
python setup_local_models.py           # 检测硬件/Ollama/已装模型，给建议
python setup_local_models.py --pull    # 自动拉取推荐模型
```

分科路由口径（8GB 显存实测）：

| 科目 | 首选模型 | 需显存 |
| :--- | :--- | ---: |
| 数学/数电/模电/电路/信号/通信/408/真题 | deepseek-r1:7b | 5.91GB |
| 政治/英语 | qwen3:8b | 6.26GB |
| 文档处理/OCR 纠错（批量） | qwen3:4b | 3.82GB |
| 电路图理解（VLM） | qwen2.5vl:7b | — |

> 模型默认存 `C:\Users\<你>\.ollama\models`；C 盘紧张可
> `setx OLLAMA_MODELS "D:\ollama-models"` 后重启 Ollama。
> 没有本地模型时，在「设置 → AI 服务」填云端 Key 即可自动兜底。

## 六、常用维护命令

均在 `backend-main-fastapi/` 下执行。

```bash
# 健康检查
python scripts\diagnostics\check_env.py            # 环境自检
python scripts\diagnostics\api_health_check.py     # 接口健康
python -m pytest tests/ -q                         # 后端单测

# 知识库
python -m services.kb_pipeline                     # 体检：如实报告缺什么
python -m services.kb_pipeline --heal              # 自愈：缺什么补什么
python -m services.kb_pipeline --heal --embeddings # 顺带补向量

# 数据
python scripts\backfill_quiz_meta.py               # 刷题 year/paper/题号 回填（预览）
python scripts\backfill_quiz_meta.py --apply       # 实际写库（先自动备份）
python migrate.py                                  # 数据库迁移

# 前端（仅改前端时）
cd frontend && npm install && npm run dev          # 开发
cd frontend && npm run build                       # 构建（自动输出到 ../backend-main-fastapi/static）
```

## 七、故障排查

| 现象 | 处理 |
| :--- | :--- |
| 页面打不开 / 502 | 先跑 `check_env.py`，看是不是依赖或 `static/` 缺失 |
| 端口被占 | 双击 `停止.bat`；或 `netstat -ano \| findstr :8000` → `taskkill /PID <pid> /F` |
| 手机访问不了 | 见上「局域网」排查 4 条 |
| 本地 AI 不生效 | `python setup_local_models.py` 检查；或打开 Ollama；或配云端 Key |
| 检索不到内容 | `python -m services.kb_pipeline` 看分块/向量状态，缺向量则 `--heal --embeddings` |
| 控制台中文乱码 | PowerShell 显示问题，文件本身是 UTF-8；执行一次 `chcp 65001` |
| `.bat` 双击闪退 | 检查是否有 UTF-8 BOM；`python tools/make_bats.py` 重新生成（自动校验 BOM） |

> 数据库备份：`backend-main-fastapi/data/backups/` 与 `database/*.db` 下有多份历史快照。
> 磁盘紧张时可清理旧备份（保留最近 1–2 份即可），本项目根另有 `_backup_20261010/` 是本次重构前的安全备份。
