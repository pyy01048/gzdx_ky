# 01 · 项目总览与现状

> 面向**贵州大学 834 电子技术基础**（数字电子技术 + 模拟电子技术）的本地化考研备考平台。
> 定位：**个人单机使用**为主，局域网良好时可通过局域网推送给手机/平板；后续可能开源供他人使用。
> 核心原则：**数据不出网**（本地模型 + 本地知识库），需要更强能力时可选云端 API 兜底。

---

## 一、技术栈

| 层 | 技术 |
| :--- | :--- |
| 后端 | FastAPI · SQLAlchemy 2.0 · SQLite（单文件）· APScheduler · uvicorn |
| 前端 | React 18 · Vite 5 · Zustand · React Router（HashRouter）· ECharts |
| 检索 | SQLite FTS5 + jieba（BM25）· 向量 KNN（bge-small-zh-v1.5，fastembed）· RRF 融合 · LLM/bge 重排 |
| OCR | RapidOCR（PP-OCRv4 ONNX）· pypdfium2 渲染；可选 PaddleOCR 微服务（端口 8888） |
| 本地模型 | Ollama（deepseek-r1:7b / qwen3:8b / qwen3:4b / qwen2.5vl:7b 等） |
| 微调 | Qwen2.5-3B + LoRA（peft / trl，可选） |
| 网盘 | 百度网盘开放平台（OAuth + 自动续期） |

前端 `npm run build` 的产物**直接输出到** `backend-main-fastapi/static/`，
所以只改后端时不需要 npm；改前端后构建即自动部署。

## 五、AI 与模型（双层）

| 层 | 说明 |
| :--- | :--- |
| 本地 | Ollama（`127.0.0.1:11434`），按科目自动选模型，未启动自动跳过 |
| 云端 | DeepSeek / 豆包 / 通义千问等 OpenAI 兼容接口（设置页填 Key） |
| 路由 | `services/ai_router.py`：识别科目 → 选模型 → 本地不可用降级云端 |
| 检索增强 | Query 改写 + HyDE + RRF 融合 + 重排 + 语义缓存 + Agentic 状态机 |
| 超时护栏 | `/api/ai/chat/router` 专用 180s（完整增强链在 CPU 上较慢），SSE 流式接口豁免 |

详见 [02-启动与使用指南.md](02-启动与使用指南.md) 的模型安装部分。
