# 03 · 刷题中心 与 院校库（对标 txkyer / gitgraduate）

本文档说明两大 benchmark 模块的**功能、数据口径（含诚实的局限）、接口契约**，
供使用与二次开发参考。

参考标杆：
- **gitgraduate.com/question-bank**（考研真题题库）→ 刷题中心的「结构化索引 → 题号网格 → 逐题训练」形态。
- **txkyer.cn**（通信电子考研择校数据）→ 院校库的「热度榜 + 多维筛选 + 核心数据表格 + 院校详情」。

> 本平台是**统一的个人 834 电子技术基础**系统，不是两个独立单功能站。
> 因此把 gitgraduate 的「年份×科目×题号」思想落到本平台的真实数据轴
> （科目 数电/模电/公共课 × 章节/套卷 × 题号），把 txkyer 的数据丰富度落到院校库，
> 而**不照搬**与本站数据不符的「数一/数二/数三」「2009–2026 完整题号」等结构。

## 一、刷题中心 `/quiz`

### 1.1 三个 Tab
| Tab | 数据轴 | 说明 |
| :--- | :--- | :--- |
| 按知识点 | 科目 → 章节/知识点树 | 整科或单章练习 + 掌握度进度条（`/api/taxonomy/tree`） |
| **真题套卷 / 按年份** | 套卷(paper) 或 年份(year) | 本次重做：改为后端聚合，题号网格，点击直达单题 |
| 错题收藏 | 错题本 + 本地收藏 | 全部重练 |

### 1.2 「真题套卷 / 按年份」子视图（对标 gitgraduate）
- **真题套卷**：列出 79 份真题卷（如「贵大16-25真题」「贵州大学电子技术基础真题16-21」「25王道408历年真题」），
  每份显示题数、涉及科目、年份（若有）。点「载入题号」→ 拉取该卷全部题目 → 渲染**题号网格**。
- **按年份**：列出能可靠解析年份的 18 个年份（2009–2026），每年显示各科目题数。点开 → 该年题目网格。
- **题号网格**：每题一格，格子颜色=对/错，角标=做过次数；点任意格 → 从该题开始练习。
  支持「网格 / 列表」两种视图。

### 1.3 诚实的数据口径（重要）
本平台题库 **9171 题**中：
- **7300 题来自教材/知识库**（按章节组织，**无年份**）——这是主力练习题；
- **1864 题来自真题**，加上年份明确的 408/管综/法硕真题，共 **3008 题归入 79 份套卷**；
- 只有 **725 题**能无歧义解析出年份（`year` 列）；多年合集（如「16-21真题」）**不猜单一年份**，靠套卷归组；
- `question_no` 是**套卷内按录入顺序的序号**，不是原卷题号（原卷题号无法从 OCR 文本可靠还原）。

> 因此「按年份」只覆盖真题子集，**不伪造年份**；教材题走「按知识点」轴。
> 这是对 gitgraduate「年份×科目×题号」形态在**本站真实数据**上的诚实落地。

回填逻辑见 `scripts/backfill_quiz_meta.py`（幂等，`--apply` 前先自动备份）。

### 1.4 接口契约（`/api/quiz`）
| 方法 | 路径 | 说明 |
| :--- | :--- | :--- |
| GET | `/questions` | 题目列表。筛选：`subject/chapter/difficulty/source/question_type/q(关键词)/year/paper`；`mode=random/sequential/weakness`；带 `paper` 时按 `question_no` 升序 |
| GET | `/papers-index` | **真题套卷索引**：`{total, papers:[{paper,count,year,year_label,subjects:{科目:题数}}]}` |
| GET | `/years` | **年份×科目聚合**：`{total_years, years:[{year,total,subjects:{科目:题数}}]}`（年份降序） |
| GET | `/stats` `/subjects` `/sections` `/weak-points` `/wrong-reasons` | 统计与分项导航 |
| POST | `/submit` | 提交答案，答错自动入错题本 |
| POST/PUT/DELETE | `/questions[/{id}]` | 题库管理（`/quiz-bank` 用） |

## 二、院校库 `/kaoyan/schools`（对标 txkyer）

### 2.1 页面结构
1. **热度榜 TOP10**：来自 `/api/kaoyan/analysis/hot?limit=10`，显示排名/院校/层级/热度。
2. **筛选区**：地区（前端由省份派生大区）/ 层级（985/211/双一流/一本/二本/民办/双非）/ 省份 / 关键词（含别名）/ 专业代码（0854 专项）。
3. **排序**：热度 / 拟录取 / 复录比 / 录取均分 / 名称。
4. **核心数据表格**（对标 txkyer 列集）：

| 列 | 字段 | 来源 |
| :--- | :--- | :--- |
| 层级 | `level` | kaoyan_schools |
| 省份 | `province` | kaoyan_schools |
| 学校 | `name` | kaoyan_schools |
| 院校信息 | `college_count` / `major_count` | 聚合学院数/专业方向数 |
| 进复试 | `retest_count` | 聚合 admissions |
| 拟录取 | `admit_count` | 聚合 admissions |
| 复录比 | `retest_ratio` | 进复试/拟录取 |
| 录取均分 | `admit_avg_score` | 聚合 admissions |
| 专业课均分 | `major_avg_score` | 聚合 admissions |
| 星级 | `star` | **层级派生**（见下） |
| 操作 | — | 详情 / 对比 / 收藏 |

5. **院校详情** `/kaoyan/schools/:id`：基本信息 + 专业方向 + 历年分数线 + 招生数据四 Tab。

### 2.2 诚实的数据口径（重要）
- **热度 `heat`**：数据库**没有「报考人数」列**，热度是**透明派生的代理指标**：
  `heat = 拟录取人数 × 1.0 + 拟招生人数 × 0.3`（口径见 `routers/kaoyan.py::_aggregate_schools`）。
  它能反映「招生规模热度」，但**不等于真实报考热度**。
- **星级 `star`**：由**院校层级派生**（985→5.0，211/双一流→4.0，一本/双非→3.0，二本→2.5，民办→2.0），非官方评级。
- **层级覆盖**：493 所中仅 225 所填了 `level`；无「二本/民办」样本数据。
- **标签 `tags`**：现存值多为研招网单位代码（如 `yz_dwdm=10002`），**不可读**，暂不做标签筛选。
- **年份**：招生数据以 2026 为主（825/832 行），选 2023–2025 可能为空。

> 这些是**数据本身的缺口**，不是代码 bug。要补齐需要采集真实的报考人数/星级/层级/标签数据
> （研招网爬虫 `POST /api/kaoyan/spider/run` 已具备入口）。在拿到真数据前，
> 平台选择**透明派生 + 明确标注口径**，而不是伪造字段。

### 2.3 接口契约（`/api/kaoyan`）
| 方法 | 路径 | 说明 |
| :--- | :--- | :--- |
| GET | `/schools` | 院校列表。参数 `level/province/subject_code/keyword/year/sort/page/page_size`。每行含上表全部聚合字段 + `heat`/`star` |
| GET | `/analysis/hot` | 热度榜 TOP N：`{items:[{rank,id,name,level,province,heat,admit_count,retest_ratio,star}]}` |
| GET | `/schools/{id}` | 详情（含 `college_count`） |
| GET | `/schools/{id}/majors` `/scores` `/admissions` | 专业方向 / 分数线 / 招生 |
| GET | `/analysis/compare` `/recommend` `/heatmap` `/scatter` `/dashboard` | 对比 / 推荐 / 热力图 / 散点 / 页面聚合 |
| POST | `/assistant/query` | 自然语言择校问答 |

## 三、与标杆的差异（一句话）

| 标杆要求 | 本平台落地 | 原因 |
| :--- | :--- | :--- |
| gitgraduate 年份 2009–2026 完整题号网格 | 真题套卷 + 按年份（仅 725 题有年份）+ 知识点网格 | 本站 79% 是教材题，无年份；不伪造 |
| gitgraduate 数一/数二/数三分栏 | 数电/模电/公共课分栏 | 本站是 834 电子技术，非数学 |
| txkyer 热度榜（报考热度） | 热度榜（招生规模派生代理） | 无报考人数数据；透明派生并标注 |
| txkyer 星级标记 | 星级（层级派生） | 无官方星级数据 |
| txkyer 标签筛选 | 暂缺 | tags 存的是机器码，不可读 |
