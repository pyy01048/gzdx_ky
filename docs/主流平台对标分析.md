# 主流平台对标分析（不背单词 / 掌上考研）

> 生成日期：2026-10-23
> 目标：盘点平台与「不背单词」「掌上考研」的功能差距，记录本轮已补齐项与后续建议。

## 一、与「不背单词」对标

不背单词的核心体验：**真实语境学词 + 间隔重复 + 轻量学习流**。

| 功能 | 不背单词 | 本平台 | 状态 |
|---|---|---|---|
| 词书体系（四六级/考研/雅思） | 多词书可选 | `word_decks`：考研核心 5,714 词 + 考研扩展 69 词 + 用户自建词库 | ✅ 已有，可扩展 |
| 每日新词配额 | 有 | Words 页 `daily_quota`（本地设置） | ✅ 已有 |
| 间隔重复（FSRS/SM-2） | 自有算法 | FSRS-4.5 + SM-2 兼容回退，`review_schedules` 统一调度 | ✅ 已有 |
| 真题/真实语境例句 | 影视/真题例句 | 5,530 大纲词全部带 NETEM 真题例句 + 中文翻译 | ✅ 本轮补全 |
| 词根词缀 | 有 | `words.root` 字段 + `word_roots` 表 | ✅ 已有 |
| 同近义词 / 短语 / 同根词 | 有 | `words.extra` JSONB（KyleBing 结构化数据），4,979 词已 enriched；PDF 导出已输出；前端复习卡片 + 列表详情已展示 | ✅ 本轮补齐 |
| 拼写练习 | 有（拼写模式） | 平台暂未做拼写输入模式（复习为「看词→回忆」），后续可加 | 🔵 建议 |
| 熟词僻义 / 词意联想 | 有 | 平台词库含多义项（KyleBing trans 多义），未做专门 UI | 🔵 建议 |
| 例句跟读 / 发音 | 有真人发音 | 前端有 TTS 朗读（Volume2 按钮，浏览器语音） | ✅ 基础版 |
| **单词本 PDF 导出** | 纸质导出（好用的点） | `GET /api/words/export-pdf`：A4 封面 + 单词/音标/词性/释义/词根/真题例句/同近义/短语；支持 deck/status/tag/search 筛选；标题自动用词库名；5000 词上限并提示截断 | ✅ 本轮增强 |
| 学习统计 / 打卡 / 成就 | 有 | GrowthPage / Insights / Planner / 学习日历 | ✅ 已有 |
| 每日到期复习队列 | 有 | Words 页「今日到期」复习队列 + 评分（忘/难/良/易） | ✅ 已有 |

### 不背单词对标结论

核心能力（真实语境例句、词根、同近义、间隔重复、PDF 导出）已具备。本轮重点增强了 **PDF 导出** 与 **同近义/短语** 两个不背单词式卖点。
后续优先级建议：**拼写练习模式**（背单词闭环中用户主动输出最弱环节）、**熟词僻义专题**（可利用 KyleBing 多义项 + 真题例句做）。

## 二、与「掌上考研」对标

掌上考研的核心体验：**院校/专业数据全 + 分数线/报录比直观 + 智能择校**。

| 功能 | 掌上考研 | 本平台 | 状态 |
|---|---|---|---|
| 院校库（列表/搜索/筛选） | 有 | KaoyanSchools 页，1,150 所，地域/层次筛选 | ✅ 已有 |
| 院校详情（简介/官网/专业） | 有 | KaoyanSchoolDetail：简介、官网、专业列表、招生数据、通知 | ✅ 已有 |
| 专业库（代码/门类/考试科目） | 有 | kaoyan_majors 6,341+ 条，含考试科目/参考书 | ✅ 已有 |
| 历年复试线（院线） | 有 | kaoyan_scorelines 181,654 条（2022-2026，逐专业院线） | ✅ 已有 |
| **国家线（A/B 区，全学科）** | 有 | 新增 `kaoyan_national_lines` 表（44 条：2025/2026 全学科门类 A/B + 政治/数学单科）；`GET /api/kaoyan/national-lines` 已上线 | ✅ 本轮补齐 |
| 报录比 / 录取均分 | 有 | kaoyan_admissions 表 + 详情页「各专业均分对比」 | ✅ 已有 |
| 院校对比 | 有 | KaoyanCompare 页（多校对比） | ✅ 已有 |
| 智能推荐（按分数/地域/专业） | 有 | KaoyanRecommend / analysis/recommend | ✅ 已有 |
| 考研资讯 / 招生简章 | 有 | kaoyan_notices + /notices 接口 | ✅ 已有 |
| 分数线走势图 | 有 | analysis/trend + scatter + heatmap | ✅ 已有 |

### 掌上考研对标结论

数据面（院校 1,150 所、院线 18 万+、国家线、报录比）已基本对齐甚至超过掌上考研。本轮补齐了 **国家线 A/B 区数据 + API**，这是此前唯一的明显缺口。
后续建议：把 `kaoyan_national_lines` 接入学校详情页（国家线 vs 院线对照图），并补 2022-2024 国家线（当前 CSV 仅 2025/2026，可从研招网/公开数据抓取历年）。
