### a.3 半成品 / 坏状态
1. **P2-2 空库伪装成功（误导，高优先修）**：`pages/Words.jsx:376` 无条件渲染卡片标题“今日单词已全部复习完成”，`:379` 给“重新开始今日复习”。实测 words=0、无词书，本应是“尚未选词书 / 词库为空”，却给绿色完成态，让用户以为今天任务已完成。`:340` 的“今日待复习”直接读 `stats.due_today`，0 时无任何引导。
2. **多套调度并存**：words 表自带 SM-2 列、flashcards 自带一套、`review_schedules` 又是统一表、还有 ebbinghaus_items；单词/卡片/错题各算各的到期日，Dashboard 的“待复习队列”难以统一（`dashboard_service.get_review_queue`）。
3. **算法停留在 SM-2/艾宾浩斯**：`algorithm` 字段已预留（learning.py:32）但未见 FSRS 落地；记忆负担预测、难度/稳定性缺失（对照建设标准的 FSRS-4/5）。
4. **版权内容缺失**：words 表有 phonetic/example 字段但库为空，没有柯林斯/考试真题例句的授权来源（版权风险，见 02 标准）。
5. 单词/卡片两个入口分属“练习”下拉，卡片表又定义在 errors.py，归属混乱（架构债）。

### a.4 缺失
- 词书市场/选书、每日新词与复习配额（goals 已有 `daily_new_words/daily_review_words` 字段 `learning.py:72-73`，但单词页未消费）。
- 拼写、听音、看词选义/看义选词多题型；熟词僻义、词根串联；学习提醒/连续打卡联动。
- 无 FSRS；无遗忘曲线看板；无“今日预估记忆保留率”。

### e.4 关键算法：FSRS（沿用 02 标准结论）
- 三变量：稳定度 **S**、难度 **D**、记忆状态；保留率 `R(t) = (1 + F·t/S)^(-1)`（FSRS-4 形式，t 为距上次复习天数，F≈请求保留率对应因子，目标保留率默认 0.9）。
- 评分后按四档更新 S/D，并由目标保留率反解下次间隔 `I = S/F · (R_target^(-1) - 1)`；四档映射 Again/Hard/Good/Easy。新卡首评给初始 S/D。
- 到期队列 = `now >= next_review_at`；Dashboard“待复习”即各类 item 到期数之和。
- 开源借鉴：**open-spaced-repetition/py-fsrs**（约 94★，MIT，可直接作 Python 参考/依赖，许可友好）；**fsrs4anki**（约 4K★，AGPL-3.0，**只参考参数/调度逻辑，勿直接拷入闭源分发**）；Anki 本体（ankitects/anki，约 32K★，AGPL-3.0）仅作产品形态参考。SM-2（words 表现有 ease_factor/interval/reps/lapses）作为回退算法保留。
- 音频 TTS 可走服务端合成或授权音频；例句/词典（柯林斯等）**必须授权**，无授权先用自造/开源例句并在 license_note 标注。

## f) 数据从 0 到有（冷启动）
- **词书与词条导入**：直接用现成 `POST /api/words/batch-import`(words.py:333)、`/import-text`(:358)、`/import-excel`(:461)。
- 建议格式（Excel/CSV，UTF-8）：`word, phonetic, pos, meaning, root, example, example_cn, tag, content_source`；批量归到某 word_decks.id。
- 冷启动词单：考研英语一/二核心词（按考纲组织），先小规模 2000–3000 词验证出队/评分/到期，再全量。
- **质量门**：word 非空且 deck 内唯一（去重：trim + 小写规范化）；meaning 必填；音标/例句可空但 content_source 必须可溯源；导入按批次 batch_id，失败回滚；导入后自动给每个词建 `review_schedules(state=0)` 初始记录，保证 /due 能出队。
- 与全局次序：在“目标/科目”之后导入（F1-05 onboarding 第 3 步）；导入后 Dashboard“今日待复习”、streak 才有数据。
