### a.3 半成品 / 坏状态（实测问题）
1. **P1-1 冷启动“后端不可达/橙条”，与健康页 7/7 矛盾（已查清根因，非接口 500）**
   - 橙条渲染点：`Dashboard.jsx:1040-1046`，仅当 `status==='error'` 显示“实时数据暂不可用，正在展示本地缓存”。`status` 由 `loadAll()` 的 `.catch` 置 `'error'`（`:166-177`）。
   - 首屏**只**请求聚合大接口 summary；一旦后端未就绪/冷库聚合慢/被 `TimeoutGuardMiddleware`（`main.py:161`）超时，即进 error 态。
   - error 态**默认不自动重试自愈**：只有 `autoRefresh` 打开才 30s 轮询，而自动刷新默认关（`Dashboard.jsx:151-185`）。用户必须手动“重试”或刷新。
   - 全局 `backendOnline`（useStore.js:123 / sync.js:164-168）是**第二套健康口径**，TopNav.jsx:91 据它显“离线”。健康自检页 `/data-center` 是**第三套口径**（8 域独立探测）。
   - 实测（2026-10-17 09:25 PowerShell + 浏览器暖机）：经 5175 代理 `GET /api/dashboard/summary` 200（约 103KB）、`/api/health` 200、数据中心 8/8 全绿（108–166ms）；暖机后橙条不复现，仅冷启动首屏“待复习卡”短暂“后端不可达”，刷新即愈。CORS 实测已放行 5175。
   - **判定**：启动时序竞态的临时降级 + 失败不自愈 + 三套健康口径，不是 summary 稳定故障。
2. **倒计时口径不一致 + 届别歧义（P2-6）**：summary 返回 `exam_date=2027-12-18, days_left=427, exam_year=2028, is_official=false, source=用户配置（该日期与教育部公布值不一致，请核对）`；院校库倒计时卡却显 426 天（`assets/07-schools/25_kaoyan_schools.jpg`）。用户口述“2027 考研”，该日期按届算为 **2028 届**（初试在 2027 年底）。存在两处各算各的天数。
3. **空数据但引导不足**：summary 实测 `kpi` 全 0、`module_progress` 全部 `no_target`（因未配置目标 + 业务数据空）。首页没有“先去设置目标 / 去导入数据”的明确引导，只呈现一堆 0 与“本机估算”。
4. **P2-9 学习计划模板套话**：`/planner`、`/kaoyan/plan` 每周文案重复“章节推进（数学+英语单词）并完成课后习题”，未按 goals 的目标科目（0854 数电等）个性化。
5. **P2-5 /insights 空态只有一张空卡**，无图表骨架，加载/空/错误三态不完整（截图见 `assets/06-wrongbook/22_insights.jpg`）。

### a.4 缺失
- 后端 `get_summary` 各子聚合无保护性降级（任一子查询抛错→整接口 5xx），是冷启动放大成“整页不可用”的隐患点（`dashboard_service.py:611-694` 顺序 await）。
- 无统一“数据新鲜度/最后同步时间”徽标；无“空数据 vs 离线 vs 部分失败”的区分。
- 无学习热力图（GitHub 风格）的稳定数据源口径（profile/insights 各取 study_events/study_stats，易再产生口径漂移）。

## f) 数据从 0 到有（冷启动）
仪表盘自身不产数据，它依赖目标、任务、学习行为、复习队列先存在。冷启动次序（与 00 总览 §7 一致）：
1. **写 goals**：通过设置页或脚本写入 北林/0854/正确初试日期/350 与分科目标、每日 focus/新词/刷题目标（对应 goals 字段，`learning.py:52-74`）。写完 summary 的 `module_progress` 才会从 `no_target` 变为可计算。
2. **配 subjects/subject_chapters**（已 37 科目 244 章节），让任务/计划能挂科目与章节（tasks.subject_id/chapter_id）。
3. **灌业务数据后产生行为**：导入单词（02）、章节题（03）、真题（04）后，用户复习/答题写 `study_events/study_stats/quiz_attempts/review_schedules`，streak/热力图/薄弱点/复习队列才有值。
4. **演示数据（可选，仅 dev）**：提供脚本生成最近 30 天 study_events 演示热力图（标 `demo=true`，严禁进生产，避免重蹈 `/kb-import` 写死假数据 P0-2）。
- 质量门：goals 日期必须通过“届↔日期”校验；学习事件按 (user,event_date,type) 唯一，避免 streak 虚高。
