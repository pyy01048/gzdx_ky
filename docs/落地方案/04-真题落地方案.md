# 04 · 真题（按年份整卷 / 模考 / 估分 / 逐题解析）落地方案

> 范围：把现在藏在 `/quiz` 内的“年份/套卷”视图升级为**独立真题中心**（按年份×科目×卷种×题号），含整卷模考、答题卡、倒计时、自动判分/估分、逐题解析。证据基于对 `D:\平台` 只读审计（2026-10-17）。对标 gitgraduate 实访结论见上级目录 `research/gitgraduate-recon.md`。

## a) 现状

### a.1 页面实访
![图4-1 真题“按年份”网格内嵌在 /quiz 中：切换后 URL 仍是 /quiz，不可分享/书签某年某卷](assets/04-realexam/11_quiz_byyear.jpg)

gitgraduate 对标（实访，详见 `../research/gitgraduate-recon.md`）：数学真题库按「年份(2009–2026) × 卷种(一/二/三) × 题号」三维网格组织，格子色深=全站做过人数热度；真题原卷库为文档式阅读（题型/分值 + 逐题 ABCD + 页码 + 计时 + 笔记）。这正是本模块要对齐的组织方式。

### a.2 已实现（前端 / 两套后端 / 表）
- **前端**：真题年份视图由 `pages/QuizYear.jsx` 承担，被 `pages/QuizHome.jsx` 内嵌、`pages/Quiz.jsx` 容器以 `view` 切换（Quiz.jsx:53,229-264）。**没有独立路由**：切到年份视图 URL 仍为 `/quiz`（hash 路由下 `/#/quiz`），无法直达/刷新保持/收藏/分享“2024 数学一”。
- **后端实际有两套，且职责其实不同（字段级已核实）**：
  - **真题套卷轨 `routers/papers.py` prefix `/api/papers`**：`GET /subjects`(:43)、`POST /build`(:61)、`POST /save`(:81)、`GET `(:94)、`GET /{id}`(:117)、`/export`(:147)、`DELETE /{id}`(:163)、`GET /filters/years`(:180)、`/filters/paper-types`(:190)、`/indexed`(:201)、模考作答 `POST /attempts/start`(:221)、`/attempts/submit`(:240)、`GET /attempts/{id}/report`(:250)、`/attempts/history`(:260)。服务 `services/paper_builder.py`。
  - **规则组卷轨 `routers/exam.py` prefix `/api/exam`**：`POST /build`(:41)、`POST /{session_id}/submit`(:62)、`GET /sessions`(:74)、`/sessions/{id}`(:84)、`GET /blueprints`(:112)、`POST /search`(:138)。服务 `services/exam_engine.py`。
  - quiz 里也透出真题索引：`GET /api/quiz/papers-index`(:556)、`GET /api/quiz/years`(:622)。
- **表（字段已核实）**：
  - `papers`（`core/models/questions.py:157`）：title、subject_id/subject、rules(JSON)、total_score、**year(真题年份)**、**paper_type(卷种：数学一/英语二)**、**is_mock(false=真题套卷/true=用户自建)**(:167-170)。
  - `paper_questions`（`:181`）：paper_id、question_id(可置空)、**seq(卷内题号)**、content/options/answer/analysis **快照**、question_type、difficulty、**score(分值)**、avg_score、attempt_count(:187-200)。
  - `paper_attempts`（`:208`）：started_at/submitted_at、status(ongoing/submitted/expired)、total_score、correct_count、duration_seconds。
  - `paper_answers`（`:231`）：paper_question_seq、user_answer、is_correct、score、time_spent_seconds。
  - 组卷轨：`exam_blueprints`(:25)、`exam_sessions`(:50)、`exam_answers`(:87)（`core/models/exams.py`）。
- **数据现状**：papers=0（health 实测），真题为空。

### a.3 半成品 / 坏状态
1. **P2-1 无独立路由（核心体验问题）**：年份网格、整卷、单题都在 /quiz 内 view 切换，无 URL 语义；用户不能把“2024 数学一第 3 题”发给研友/加入收藏夹，刷新丢上下文。
2. **双轨认知混乱**：`/api/papers`（真题套卷，year/paper_type/快照/attempt）与 `/api/exam`（blueprint 规则组卷/session）并存，前端 QuizYear 还通过 `/api/quiz/years`、`/papers-index` 取数，三处都能摸到真题，边界不清，后续易重复开发。
3. **整卷模考闭环前端不完整**：后端已有 attempts/start、submit、report、history（papers.py:221-260）与 status/计时字段，但前端年份视图只是入口网格，缺独立的“整卷答题页 + 答题卡 + 倒计时 + 交卷估分报告”页面。
4. **空数据**：papers=0，年份网格空；无真题时也缺“去导入真题”的空态引导。
5. 数学公式/题图渲染需与章节题共用统一组件（见 03 F3-04）。

### a.4 缺失
- 按年份的真题列表页、套卷详情页、单题详情页（独立 URL）。
- 模考设置（限时/不限时、整卷/题型分段）、答题卡跳转、漏答提醒、交卷确认。
- 估分报告：总分/客观自动分/主观按得分点自评、各科目标对比、逐题解析、错题一键入复习、全站做过热度。

## e) 具体怎么做（文件级）

### e.1 前端
- **路由（改 `src/App.jsx`）**：新增
  - `/exam` → `pages/exam/ExamIndexPage.jsx`
  - `/exam/:year/:paper` → `PaperTakePage.jsx`
  - `/exam/:year/:paper/:qno` → `PaperQuestionPage.jsx`（单题）
  - `/exam/:year/:paper/report/:attemptId` → `PaperReportPage.jsx`
  旧路径保留：`/quiz` 的 QuizYear 点击改为 `navigate('/exam/'+year+'/'+paper)`；不删 QuizYear（避免回归），仅改跳转。
- **改 `pages/QuizYear.jsx`**：年份/题号格子用 `<Link>` 带 URL（可分享），数据源改调真题适配层（下）。
- **新增 `src/api/examApi.js`**（收敛三处数据口）：`listYears(subject)`、`listPapers({subject,year})`、`getPaper(id)`、`startAttempt(paper_id,{timed})`、`submitAttempt(id,payload)`、`report(id)`、`history()`——内部映射到 `/api/papers/*`；另导出 `mockBuild()` 映射 `/api/exam/build`（明确命名为“组卷”）。`/api/quiz/years`、`/papers-index` 仅在后端未提供等价口径时作为适配层内部调用，页面不再直接依赖。
- 组件复用：`MathText`（03 F3-04）、`components/States` 三态；倒计时新建 `exam/Timer.jsx`（到时调 submit，状态 ongoing→submitted/expired）；答题卡 `AnswerSheet.jsx`。
- 导航：在统一 navConfig（见00）“练习”组把“真题”指向 `/exam` 并提一级。

### e.2 后端
- **保持两轨但定边界**：
  - 真题（真实历史套卷）统一走 `/api/papers`（year/paper_type/is_mock=false，快照与 attempts 已完备）。
  - 智能规则组卷走 `/api/exam`（blueprints/sessions）。建议在两个 router 的 OpenAPI tags 与文档里显式区分；`/api/quiz/years`、`/papers-index` 标记为“适配/兼容”，逐步内聚到 papers。
- 若前端需要“年份网格 + 每卷题号 + 热度”的聚合口，建议在 papers.py 增加 `GET /api/papers/grid?subject=` 一次返回 `[{year,paper_type,paper_id,counts:[{seq,attempt_count}]}]`，避免前端 N 次请求（也可直接由现有 /filters/years + /indexed 组合）。
- 交卷判分：`/attempts/submit`(:240) 客观题写 is_correct/score（paper_answers 已支持），主观题返回参考得分点供自评（复用 exams.py answer_candidates 思路）；提交后把错题写入 error_records（接 06 服务）、知识点掌握度回写、写 study_events。

## f) 数据从 0 到有（冷启动）
- 复用 `pipeline/exam_bank_extractor.py`（真题抽取）→ `pipeline/question_schema.py`（结构/题型/分值校验）→ `scripts/import_exam_questions.py`，或经 `POST /api/papers/build`(:61)/`save`(:81) 落库。
- 导入模型：一套真题 = 一行 `papers`（year、paper_type、subject/subject_code、total_score、is_mock=false、source_url、batch_id）+ N 行 `paper_questions`（seq 题号、question_type、score 分值、content/options/answer/analysis 快照、question_id 关联到 quiz_questions 主数据）。
- 组织对齐 gitgraduate：数学按年份×卷种(一/二/三)×题号；近年每题分值、题型（选择/填空/解答）齐全；政治/英语/专业课同构。
- **质量门**：题序 seq 在卷内连续且唯一；score 合计=total_score；题型在枚举内；公式 KaTeX 试渲染通过；快照与源题 answer 一致；同(year,paper_type,seq)唯一指纹防重复导入；按 batch_id 导入，失败整批回滚；source_url 记录真题出处（版权合规：仅自用学习，不对外分发未授权原卷）。
- 次序：在章节题主数据（quiz_questions，见03）之后导入，paper_questions.question_id 才能正确关联，错题/掌握度/热度才能跨“章节题↔真题”贯通。
