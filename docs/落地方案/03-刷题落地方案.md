### a.3 半成品 / 坏状态
1. **P2-8 默认科目错位“中医综合”**：根因如上（QuizHome.jsx:126-133）。不是写死，而是“目标科目为空 + 全 0 题”时回退列表首项。修复要同时做“引导配置备考科目”和“无目标时不默认落到无关医学科目”。
2. **知识树断链**：37 科目/244 章节存在，但 knowledge_points=0；`question_knowledge_links` 无题可挂；KbMap 因此全 0（图3-3）。章节题“按知识点刷”和错题“薄弱知识点”都失去锚点。
3. **P0-1 SubjectManager 白屏**：`/subjects` DOM 有 37 科目/244 章节/编辑删除按钮但视口全白 → 科目与章节维护实际不可用，直接阻断冷启动期人工校对。验收：白屏修复后能新增/改名/排序科目章节（修复根因归 00/管理端）。
4. **管理入口缺失（P1-5）**：`/quiz-bank`、`/subjects` 无主导航入口，仅设置→管理中心卡片墙；且无角色鉴权（`utils/auth.py`）。归口见 00 的 `/admin` IA。
5. **空态文案错位**：`/textbooks` 空态写“换个阶段或关键词试试”（图3-4），像筛选无结果，而非“尚未导入教材”。
6. 真题/章节题/课后题在 `/quiz` 内混（年份视图 QuizYear 与章节练习 QuizHome），来源维度不清；`/api/quiz` 还暴露 `/years`、`/papers-index`，与 `/api/exam`、`/api/papers` 双轨交叉（见 04）。

### a.4 缺失
- 完整五层“学科→教材→章→节→知识点”与题目多标签（题型、难度、来源=平时题/课后题、年份、正确率、掌握度）。
- 数学/专业课题的**公式渲染**（KaTeX/MathJax）与图文混排、图表题支持未在页面形成统一组件。
- 主观题对照答案自评 / AI 评分（exams.py 已有 pending_questions/answer_candidates 雏形，未接到章节练习）。
- 题目收藏、错因自动入错题本、按掌握度出题（薄弱优先/组卷）的前端闭环。

### e.5 关键算法 / 开源 / 许可证
- **题目去重指纹**：对题干做规范化（去空白/公式归一）后 SHA-256，入库 content_hash 唯一索引；导入时命中则走“合并/跳过/更新”。
- **掌握度**：基于该知识点下作答正确率 + 最近度加权（复用 services/kp_mastery 思路），分 4 态（未学/学习中/薄弱/掌握），薄弱优先出题。
- **公式渲染**：KaTeX（github.com/KaTeX/KaTeX，MIT，服务端/前端均可，渲染快）为主；MathJax（github.com/mathjax/MathJax，Apache-2.0）作为复杂场景备选；二者择一全站统一。
- 题库/考试系统可参考 **mindskip/xzs（学之思，Java+Vue）** 的题库结构与组卷字段设计（语言栈不同，仅借鉴数据模型与交互，不引代码）。

## f) 数据从 0 到有（冷启动）
复用现成管线（见 00 §7，禁止重造）：
1. **教材与章→知识点**：`pipeline/import_textbooks.py` + `pipeline/textbooks_seed.json`（含 26 本教材种子）建教材/章节；用 `pipeline/classifier.py`/`document_normalizer.py` 从已入库文档抽取知识点写入 knowledge_points + relations。**这步是题/错题/图谱的前置**（当前 knowledge_points=0）。
2. **章节题抽取与导入**：`pipeline/exam_bank_extractor.py` 抽取 → `pipeline/question_schema.py` 校验结构 → 经 `POST /api/quiz/import`(:761) 或 `scripts/import_exam_questions.py` 落 quiz_questions；Markdown 走 `/import/markdown`(:1387)+`/import/confirm`(:1453) 两步确认。
3. **导入字段规范**：`{科目, 教材, 章, 节, 知识点[], 题型, 题干(LaTeX), 选项, 答案, 解析, 难度, 来源(平时/课后), 年份(可选)}`。
4. **质量门**：schema 必填/枚举校验；公式可渲染校验（KaTeX 试渲染不报错）；content_hash 去重；answer 与 options 一致性；按 batch_id 导入、失败整批回滚；抽样人工校对；导入后回算 knowledge_points 题数与掌握度。
5. **次序**：goals→subjects/subject_chapters（修白屏后人工校对）→knowledge_points→quiz_questions→作答产生 attempts/错题/掌握度。先导入目标科目（数电/信号等 0854 相关），不导入无关医学题库，避免再次出现“默认中医综合”。
