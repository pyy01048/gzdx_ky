## 使用边界（README 同步声明）

- 代码 MIT；**题库 / 教材 / 真题 / 词库版权归原权利人**，本平台仅限个人学习研究，不提供公开分发。
- 采集遵守：串行限速、仅访问公开接口、请求留痕（见 `scripts/datasource/`）。
- 院校热度/星级为派生估算值，UI 保持"估算"角标，不伪造真实报考人数。
