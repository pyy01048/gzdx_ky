1. 真题单一真相源：一套表承载所有真题（含专业课新导入），exam/papers 两个 API 读同一底层，写入只走一条管线；决策进 ADR。

3. 学习闭环真实可写：一次完整用户操作（刷题→交卷→错题→复习→打卡→时长）后，六张行为表全部有行，e2e 固化。

### 3.2 真题数据源收敛（M，需决策 → ADR-004）

### 3.4 仪表盘第四态（S–M）

```jsx
// Dashboard 顶层状态机：loading / error / empty / partial
const status = useMemo(() => {
  if (loading) return 'loading'
  if (fatalError) return 'error'
  if (allModulesEmpty) return 'empty'
  if (failedModules.length > 0) return 'partial'   // ← 新增
  return 'ok'
}, [loading, fatalError, failedModules, allModulesEmpty])
```

partial 态：顶部黄条"以下模块数据暂不可用：{failedModules}，其余正常"，每个失败模块卡片内独立重试按钮（沿用已有指数退避重试 1/2/4/8/16s）。字段级降级保留，但不再"静默装作正常"。
