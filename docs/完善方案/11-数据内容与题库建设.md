### 1.2 导入质量目标（用户既定要求）

OPEN-DECISIONS 登记："用户希望导入准确率 99%，需可验证的验收机制：抽样验收 + 规则校验，低于阈值拒绝入库"。**这个目标至今没有固化为管线门禁**——历次导入报告（docx/57、65、66、67）有逐源审计，但都是一次性人工运动，不是常态化闸门。

### 1.3 版权

真题 PDF（LFS）、教材分块、ECDICT 词库等在库。个人学习使用风险低，但**公开仓库分发**是另一回事（01 文档转私有 + 声明）。数据建设本身不受影响，继续做。

## 2. 完善标准

1. **质量门常态化**：任何批量导入必须过"规则校验 → 抽样人工验收 ≥99% → batch_id 可回滚 → 行数台账"四步，低于阈值整批拒绝（用户既定要求落地为代码）。
2. warn 题清零或显式下架：216 道逐题处置（修复/下架/转题型），处置率 100%，留回滚 SQL。
3. 跨源去重有权威规则：展示层去重 + 存储层合并双轨，重复组从 113 → <20（剩余为合法跨年同题）。
4. 专业课真题闭环：数电/模电/电路真题从 503 chunks 抽取入库，年份/套卷/题号三字段齐全，is_past_exam 全量回填。
5. 题库健康面板常态化：warn 数/重复组/无解析数/真题覆盖率进 /api/health 或管理端仪表盘，只降不升。
6. 数据口径单一来源：README/面板/报告全部从 `readme_counts.py` 同一查询出数（12 文档）。

## 3. 落地步骤

### 3.1 warn 题治理（M，先做——存量质量止血）

```powershell
cd D:\研途\gzdx_ky\backend-main-fastapi
# 1) 导出 216 题明细（题目/选项/答案/解析/warn 原因）
python scripts/quiz_health_check.py --export-warn ..\..\docs\reports\warn-questions-$(Get-Date -Format yyyyMMdd).csv
```
逐题处置决策树：
```
warn 原因
 ├─ 选项缺失/占位（如 "A. 略"）→ 能从解析/源文档补全 → 修复 + validation_status=passed
 ├─ 答案与题型不符（多选答案实为多空填空）→ 转 fill 题型（docx/56 已有先例与回滚脚本模式）
 ├─ 解析错位/OCR 碎片 → 源文档重抽（3.3 管线）
 └─ 无法修复 → is_available=false 下架（保留数据，可回滚）
```
铁律（沿用 docx/56 模式）：处置前备份表 `bak_quiz_warn_<date>`，每批附回滚 SQL，处置后全量 pytest + 刷题中心 smoke。

### 3.2 跨源去重（M）

规则定版（写进 ADR-003 题目 canonical schema 的补充章节）：
- **判重键**：`normalize(content) + subject + chapter`；normalize = 去空白/全半角/标点归一/选项顺序无关哈希。
- **展示层**：刷题/组卷查询按判重键 DISTINCT ON，保留优先级：真题来源 > 教材 > 开源题库；同优先级保留解析最全者。
- **存储层**：`scripts/migrations/dedup_quiz_cross_source.py --dry-run` 出合并报告（113 组逐组列保留/合并/丢弃），人工审核后 `--apply`；被合并题的作答记录/收藏外键迁移到保留题（**不能直接 DELETE 留下孤儿 attempt**）。
- 跨年同题（英语真题不同年份题干相同）是合法重复：判重键加 year 维度豁免，保留年份标注。
- 验收：重复组 <20 且全部为合法跨年；刷题中心不再出现"同一题刷两遍"。

### 3.3 专业课真题抽取导入（L，核心增量）

源：知识库中 503 chunks 真题源文档（扫描版 OCR 正文已在 knowledge_chunks）。管线：

```
步骤 1  定位源文档：documents 按 doc_type/文件名筛出数电/模电/电路真题卷
步骤 2  卷面结构识别：年份/套卷头 → 大题号 → 小题号（正则 + 本地 qwen3:4b 辅助结构化）
步骤 3  逐题抽取：题干/选项/答案/解析/配图（question_pages 图片链路已有）
步骤 4  规则校验器（质量门，代码固化）：
        - 客观题：选项 ≥2、答案 ∈ 选项集、无占位符
        - 填空/计算题：答案非空、解析非空（真题允许无解析但标记）
        - 题干长度/OCR 噪声比（check_ocr_quality 口径）
        - 年份 ∈ 合理区间、题号连续性与套卷内唯一
步骤 5  抽样人工验收：每批随机 10%（≥30 题）对照原卷 PDF 逐字核对，
        准确率 ≥99% 才放行；<99% 整批打回步骤 3（用户既定阈值）
步骤 6  入库：batch_id 标记 + 行数台账（导入前/后/拒绝数）+ 备份表 + 回滚 SQL
步骤 7  回填：is_past_exam=true、year、paper、question_no；挂靠知识点（taxonomy 权威树）
步骤 8  报告：docs/reports/zhenti-import-<subject>-<date>.md（沿用 docx/65 逐源审计格式）
```
脚本落位：`scripts/migrations/import_major_zhenti_pg.py`（连接走 02 文档 _conn.py；校验器独立 `services/quiz_validator.py` 供所有导入复用——**这就是 99% 目标的常态化载体**）。
优先序：数电（834 主科）→ 模电 → 电路；每年份卷完整导入后再做下一年，避免半成品卷。

### 3.4 is_past_exam 与年份全量回填（S）

```sql
-- 备份先行：CREATE TABLE bak_quiz_pastexam_<date> AS SELECT id,is_past_exam,year FROM quiz_questions;
UPDATE quiz_questions SET is_past_exam = true
WHERE source_label ~ '真题|zhenti|past' AND is_past_exam IS NOT TRUE;
-- 年份缺失但 source_label 含 19xx/20xx 的抽取回填（脚本正则，dry-run 先出清单）
```
回填后刷新 readme_counts.py，README 短板表对应行关闭（12 文档）。

### 3.5 健康面板常态化（S）

`services/quiz_health.py`（或并入现有 quality 路由）输出：
