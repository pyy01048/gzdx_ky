## 2. 完善标准

1. eslint（含 react-hooks 规则）+ prettier 进 package.json scripts、pre-commit、CI；新增代码 0 error。
2. `npm run build` 在 CI 必跑，产物 artifact 化（06 文档已落地）。
3. 重库按需分包：echarts/pdfjs/katex/mammoth 独立 chunk 且只在对应页面加载；首屏 entry gzip ≤ 300KB。
4. TS 渐进落地：新文件 .tsx 优先，api 层与 store 先迁（类型收益最大处），不追全量。
5. 依赖体积有审计记录（rollup-plugin-visualizer），每次加重依赖过评审。

## 3. 落地步骤

### 3.1 eslint + prettier（半天）

```powershell
cd D:\研途\gzdx_ky\frontend
npm i -D eslint @eslint/js eslint-plugin-react eslint-plugin-react-hooks eslint-plugin-react-refresh globals prettier eslint-config-prettier
```
`eslint.config.js`（flat config，eslint 9）：
```js
import js from '@eslint/js'
import globals from 'globals'
import react from 'eslint-plugin-react'
import reactHooks from 'eslint-plugin-react-hooks'
import reactRefresh from 'eslint-plugin-react-refresh'
import prettier from 'eslint-config-prettier'

export default [
  { ignores: ['dist', '../backend-main-fastapi/static', 'node_modules'] },
  {
    files: ['**/*.{js,jsx}'],
    languageOptions: {
      ecmaVersion: 2022,
      globals: globals.browser,
      parserOptions: { ecmaFeatures: { jsx: true }, sourceType: 'module' },
    },
    plugins: { react, 'react-hooks': reactHooks, 'react-refresh': reactRefresh },
    rules: {
      ...js.configs.recommended.rules,
      ...react.configs.recommended.rules,
      ...reactHooks.configs.recommended.rules,
      'react/react-in-jsx-scope': 'off',
      'react/prop-types': 'off',                 // 渐进 TS 替代 prop-types
      'no-unused-vars': ['warn', { argsIgnorePattern: '^_' }],
      'react-refresh/only-export-components': 'warn',
    },
    settings: { react: { version: 'detect' } },
  },
  prettier,
]
```
`.prettierrc.json`：`{ "singleQuote": true, "semi": false, "printWidth": 110 }`
package.json scripts 追加：
```json
"lint": "eslint src",
"lint:fix": "eslint src --fix",
"format": "prettier --write src"
```
```powershell
npm run lint          # 存量告警留档，error 级当轮修完
npm run format        # 单独 commit，登记 .git-blame-ignore-revs
```
pre-commit 追加（仓库根 .pre-commit-config.yaml）：
```yaml
  - repo: local
    hooks:
      - id: eslint
        name: eslint
        entry: bash -c 'cd frontend && npx eslint src --max-warnings=0'
        language: system
        files: ^frontend/src/.*\.(js|jsx)$
```
CI lint job（06 文档）追加：`cd frontend && npm ci && npm run lint`。

### 3.2 重库分包（半天）

vite.config.js 的 manualChunks 扩展：
```js
manualChunks: {
  'react-vendor': ['react', 'react-dom', 'react-router-dom'],
  'state-vendor': ['zustand'],
  'charts-vendor': ['echarts'],          // 仪表盘/统计页才加载
  'pdf-vendor': ['pdfjs-dist'],          // 文档预览/真题阅读页才加载
  'doc-vendor': ['mammoth'],             // docx 预览
  'math-vendor': ['katex'],              // 公式渲染（刷题/知识点页）
},
```
⚠️ 前提：这些库必须是**动态 import 或仅在懒加载页面里静态 import**，否则 manualChunks 只是把大 chunk 换个名字、首屏照样拉。核查方式：
```powershell
npm run build
npx vite-bundle-visualizer   # 或 rollup-plugin-visualizer，看 entry 实际引用链
```
目标：entry（index-*.js）gzip ≤ 300KB；charts/pdf chunk 只在对应路由的网络请求里出现。
pdfjs-dist 的 worker 确认走 `?url` 独立文件（已是 hash 资产即可）。

### 3.3 TS 渐进（L，新代码先行）

顺序（收益/成本比从高到低）：
1. `src/api/client.js → client.ts`：接口请求/响应类型定义（与 06 文档契约测试联动，后端 schemas.py 可生成 TS 类型：`datamodel-code-generator` 或手写 zod schema）。
2. `src/store/useStore.js → useStore.ts`：Zustand persist 键与 uid 隔离逻辑类型化。
3. `src/utils/`（14 个模块）。
4. 新页面一律 .tsx；旧页面改到哪个迁哪个。
tsconfig 已存在，vite 天然支持 .ts/.jsx 混编，无需构建改造；`npm run typecheck: tsc --noEmit` 进 CI（先只 include 已迁移目录，逐步扩大）。
