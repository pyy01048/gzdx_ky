## 三、剩余缺口清单（按优先级）

1. **【大】数据冷启动（P0-4/M2）**：章节题→真题→单词→代码题→院校→chunk_vectors 建向量，按方案 §7 次序执行质量门。
2. **【大·需决策】行级数据隔离（B4）**：要么补 user_id 全链路（大工程），要么明确「单租户/共用数据」产品定位并在文档与 UI 声明。当前靠"用户都是自家人"运行。
3. **【小】6 个漏网管理端点**：/api/errors/batch-delete、/api/quiz/review/{id}、/api/netdisk/sync|logout|refresh-token|callback ——补进 access_policy 路径表即可（集中修法）。
4. **【小】一批残留**：Textbooks.css:270 tb-fade 仍有 opacity:0 起点动画（同白屏模式）；notices.py:5-9 / notice_read.py:9-13 过期注释（仍称"无 users 表"）；.env:14/24/26 与 make_bats.py:55 的 APP_PASSWORD 残留；`'重点'.repeat` 三处；/kaoyan/compare 空库引导；Dashboard 宫格 MODULES 键不一致。
5. **【中】结构收敛**：/api/exam 双轨去留；文档计数三路 COUNT 归一；models.py 与 core/models 双定义收口（ADR-002 Phase 2）。

## 五、建议执行计划

- **阶段一·快速加固（S，立即可做）**：缺口 3+4 全部小改动，一轮构建+全量测试回归收尾。
- **阶段二·数据冷启动（L，M2 主体）**：先探查数据源与资产就位（待证项），再按 §7 次序逐域导入（每批 batch_id 可回滚、导入前后行数台账、抽样校对）；数据源文件缺失时停下来向数据提供方要数据，不造假。
- **阶段三·结构收敛（需决策）**：B4 隔离定位、/api/exam 去留、计数归一、模型双定义收口——其中 B4 与 exam 去留需要产品决策后再动工。
