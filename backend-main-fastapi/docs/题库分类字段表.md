# 08 工学题库分类与字段表

本表定义题库的统一字段，核心目标是让「真题 / 练习题 / 习题 / 考研题」四个分类可以**独立、清晰地筛选和选择**，并与已有来源性质（`source_kind`）正交，避免重复定义。

## 一、四个主分类（筛选主键）

| 分类值 | 定义 | 典型来源 | 与现有字段的映射 |
| --- | --- | --- | --- |
| `真题` | 历次真实考试试卷中的原题，含明确年份、试卷、题号 | 期末/期中卷、考研真题、竞赛卷、资格认证卷 | `source_kind='past_exam'`，且 `year/paper/question_no` 尽量有值 |
| `考研题` | 面向考研初试/复试目标的题目（真题或模拟，按考研科目体系组织） | 考研真题、考研模拟、408、公共课 | `source_kind` 可为 `past_exam/mock_exam`，`is_retest` 标识复试 |
| `练习题` | 非教材课后、非试卷原题，面向知识巩固和能力提升的配套训练题 | 自建标准题库、平台练习、模拟训练 | `source_kind='chapter_exercise/mock_exam/external_import'` |
| `习题` | 教材课后习题、章节习题，随教材章节编排，用于课后巩固 | 教材课后答案、章节习题、开放教材作业 | `source_kind='textbook/chapter_exercise'` |

> 说明：`真题` 与 `考研题` 有交叉（考研真题既是真题又是考研题）。数据库用**单一主分类字段 `question_category`** 取唯一值，由入库时的归类逻辑决定主类；来源性质 `source_kind` 作为正交的第二维度保留，便于按“真实试卷 / 教材 / 章节习题”等进一步过滤。

> 入库约束：数据库对 `source_kind='past_exam'` 强制要求 `year` 非空。无明确年份的试卷题会以 `source_kind='external_import'` 入库（`question_category` 仍保留为 `真题` 或 `考研题`），`year` 允许为空，避免伪造年份。

## 二、字段总表（quiz_questions）

| 分组 | 字段 | 类型 | 说明 | 取值/约束 |
| --- | --- | --- | --- | --- |
| 标识 | `id` | INT | 主键 | 自增 |
| 标识 | `external_id` | VARCHAR(100) | 外部唯一 ID | 唯一，如 `08bank_<slug>_<seq>`、`real_sub<科目ID>_<seq>` |
| 科目 | `subject_id` | INT | 科目 ID | 外键 subjects |
| 科目 | `subject` | VARCHAR(50) | 科目名称 | 如 力学、计算机科学与技术、数学 |
| 分类 | `question_category` | ENUM | **主分类（筛选主键）** | `真题` / `练习题` / `习题` / `考研题`，非空，默认 `习题` |
| 分类 | `source_kind` | ENUM | 来源性质（正交维度） | `past_exam/textbook/chapter_exercise/mock_exam/ai_generated/user_created/external_import` |
| 分类 | `exam_type` | VARCHAR(50) | 考试类型 | `考研/期末/期中/竞赛/资格认证/教材课后/模拟/平时` |
| 真题 | `year` | INT | 真题年份 | 索引，可空 |
| 真题 | `paper` | VARCHAR(100) | 试卷标识 | 如 408统考真题、2025本校期末 |
| 真题 | `source_paper` | VARCHAR(200) | 来源试卷名 | 可空 |
| 真题 | `question_no` | INT | 试卷内题号 | 可空 |
| 来源 | `source_platform` | VARCHAR(100) | **来源平台** | 国家高等教育智慧教育平台 / 中科UMajor / 维普 / MIT OCW / 考试资料网 / GitHub 等 |
| 来源 | `source_url` | TEXT | 来源链接 | 可空 |
| 来源 | `source_label` | TEXT | 来源描述 | 可空 |
| 内容 | `content` | TEXT | 题干 | 必填 |
| 内容 | `question_type` | ENUM | 题型 | `single/multiple/judge/fill/calc/essay/draw/proof/other` |
| 内容 | `options` | JSON | 选项 | `[{key,text}]` |
| 内容 | `answer` | TEXT | 答案 | 可空（主观题可为参考答案） |
| 内容 | `analysis` | TEXT | 解析 | 可空 |
| 内容 | `chapter` | VARCHAR(200) | 章节 | 可空 |
| 内容 | `knowledge_point` | VARCHAR(200) | 知识点 | 可空 |
| 内容 | `difficulty` | INT | 难度 | 1-5，默认 3 |
| 使用 | `is_available` | BOOL | 是否可用 | 默认 true |
| 使用 | `is_retest` | BOOL | 是否复试题 | 默认 false |
| 质量 | `is_junk` | BOOL | 是否碎片题 | 默认 false |
| 质量 | `validation_status` | ENUM | 校验状态 | `pending/pass/warn/fail` |
| 时间 | `created_at` | TIMESTAMP | 创建时间 | |
| 时间 | `updated_at` | TIMESTAMP | 更新时间 | |

## 三、典型筛选示例

- 只选工学真题：`question_category='真题'`（再按 `subject`/`subject_id` 限定具体工学专业）
- 选考研计算机 408：`question_category='考研题' AND subject='计算机科学与技术'`
- 选机械教材课后习题：`question_category='习题' AND subject='机械工程'`
- 按来源平台取数：`source_platform='MIT OCW'`
- 按考试类型取数：`exam_type='考研'`
