## 0. 全站页面骨架（PageShell）

所有页面共用同一层骨架，**禁止各页自己写 `padding` / `max-width` / 标题字号**。

```
┌─────────────────────────────────────────────────────────┐
│ .topbar  64px sticky（NAV-SPEC §2）                      │
├─────────────────────────────────────────────────────────┤
│ .main-area  max-width: var(--container-max) 1440px       │
│             padding-inline: var(--container-gutter) 24px │
│             padding-top: var(--page-top) 20px            │
│  ┌ PageHeader ──────────────────────────────────────┐   │
│  │ 标题 24px/32px   副标题 13px muted     [主操作]   │   │
│  └──────────────────────────────────────────────────┘   │
│  ┌ 工具条（筛选/搜索/视图切换）────────────────────┐   │
│  └──────────────────────────────────────────────────┘   │
│  ┌ 主体内容 ───────────────────────────────────────┐   │
│  │                                                  │   │
│  └──────────────────────────────────────────────────┘   │
│  padding-bottom: var(--page-bottom) 48px                 │
└─────────────────────────────────────────────────────────┘
```

### 0.1 三种容器宽度（页面级开关）

| 变体 | 宽度令牌 | 用于 |
|---|---|---|
| 默认 | `--container-max` 1440px | 仪表盘、设置、刷题、错题、知识图谱 |
| `is-wide` | `--container-wide` 1600px | 院校库、题库管理、通知中心（宽表 / 多列） |
| `is-prose` | `--container-prose` 760px | 文档知识库正文、讲义长文（约 38 汉字/行） |

### 0.2 PageHeader 统一规格

```jsx
<PageHeader
  title="院校库"                      // 24px/32px, --fw-semibold, --tracking-tight
  desc="共 1,284 所院校，按省份与学科门类筛选"  // 13px --muted，可选
  actions={<><Button variant="ghost">导入</Button><Button variant="primary">对比</Button></>}
/>
```

| 元素 | 规格 |
|---|---|
| 标题 | `--text-2xl` 24px / `--lh-2xl` 32px / `--fw-semibold` / `--tracking-tight` / `var(--fg)` |
| 副标题 | `--text-sm` 13px / `var(--muted)`，`margin-top: var(--space-1)` |
| 动作区 | 右对齐，主操作**最多 1 个**（Primary），次要最多 2 个 |
| 下边距 | `margin-bottom: var(--space-5)` 20px |
| 移动端 | 标题降到 20px，动作区换行到第二行，按钮全宽 44px |

> 禁止：每页标题字号不一（现状 Dashboard/KaoyanSchools/Quiz 各不相同，是 UI 不统一的主因之一）。

### 0.3 区块间距节奏

| 层级 | 间距 |
|---|---|
| PageHeader → 工具条 | `--space-5` 20px |
| 工具条 → 主体 | `--space-5` 20px |
| 主体内区块之间 | `--section-gap` 24px |
| 卡片之间 | `--grid-gap` 16px |
| 卡片内元素 | `--space-3` 12px |

## 1. 仪表盘（首页）— `/`

### 1.1 硬性要求（用户诉求）

> "仪表盘作为首页，任务打卡、学习计划、学习画像，这些全部划归仪表盘的内容"
> P0：**禁止营销式 Hero**（大标题 + 副标题 + 居中 CTA + 抽象图形）。首屏必须是**真实学习内容**。

### 1.2 版式（唯一允许非对称的页面，DESIGN_VARIANCE 4）

```
┌ 考研初试倒计时 ───────────────────────────────────────────┐  ← 通栏信息条，非 Hero
│ 距 2027 考研初试  218 天 04:12:33        设置初试日期 →    │
└──────────────────────────────────────────────────────────┘

┌ 主栏（2fr）─────────────────────┐ ┌ 侧栏（1fr）──────────┐
│ ① 今日复习队列                    │ │ ③ 学习画像            │
│  待复习 32 题 · 待背 48 词        │ │  雷达图（5 维能力）    │
│  ┌────────────────────────────┐ │ │  掌握度环形 40%       │
│  │ 错题 12 → [开始复盘]        │ │ │  连续打卡 27 天       │
│  │ 单词 48 → [开始背]          │ │ └──────────────────────┘
│  │ 卡片 20 → [开始过]          │ │ ┌ ④ 薄弱知识点 Top5 ───┐
│  └────────────────────────────┘ │ │  极限与连续      18% │
│                                  │ │  中值定理        22% │
│ ② 任务打卡                        │ │  矩阵特征值      31% │
│  [x] 高数习题 P120-134  [+新增]   │ │  …                → │
│  [ ] 英语真题 2019 T3             │ └──────────────────────┘
│  [ ] 政治第三章网课               │
│                                  │
│ ⑤ 学习计划（本周）                │
│  ┌ 一 ─ 二 ─ 三 ─ 四 ─ 五 ─ 六 ─ 日 ┐
│  │ ▓▓  ▓▓  ░░  ▓▓  ▓▓  ░░  ░░ │
│  本周应完成 18 项，已完成 11 项   │
└──────────────────────────────────┘
```

### 1.3 栅格

```css
.dash-grid {
  display: grid;
  grid-template-columns: 2fr 1fr;      /* 非对称：主次分明 */
  gap: var(--grid-gap);
  align-items: start;
}
@media (max-width: 1023px) { .dash-grid { grid-template-columns: 1fr; } }  /* 非对称在 <1024 必须回退单列 */
```

### 1.4 区块顺序（移动端重排）

桌面：倒计时 → ①今日复习队列 → ②任务打卡 → ③学习画像 → ④薄弱知识点 → ⑤学习计划
移动（单列，按「今天该干什么」排序）：倒计时 → ①今日复习队列 → ②任务打卡 → ⑤学习计划 → ③学习画像 → ④薄弱知识点

### 1.5 数据规则

- 所有数字来自真实接口，`class="tabular"`，禁止「10,000+ 用户信赖」这类虚构指标。
- 无数据时区块显示**骨架屏**而非 0（首屏加载中）；确为 0 时给引导（如「今天没有到期复习 → 去刷 10 道新题」）。
- 倒计时条：日期取自 `utils/exam.js` 统一配置；未设置时给「设置初试日期」入口，不显示假日期。

## 2. 列表页（院校库 / 题库管理 / 文档库 / 通知中心 / 错题本）

### 2.1 版式

```
PageHeader（标题 + 总数 + 主操作）
┌ 工具条 ───────────────────────────────────────────────┐
│ [搜索框 320px] [科目▾] [状态▾] [排序▾]   [视图: 表/卡] │
└──────────────────────────────────────────────────────┘
┌ 结果统计条 ───────────────────────────────────────────┐
│ 共 1,284 条 · 已选 12 项        [批量操作▾] [清除筛选] │
└──────────────────────────────────────────────────────┘
┌ 表格 / 卡片网格 ──────────────────────────────────────┐
│ （表头 sticky，行高 44px，见 COMPONENT-SPEC §3）        │
└──────────────────────────────────────────────────────┘
┌ 分页 ─────────────────────────────────────────────────┐
│                        ‹ 1 2 3 … 26 ›   每页 [20▾]    │
└──────────────────────────────────────────────────────┘
```

### 2.2 规则

| 项 | 规格 |
|---|---|
| 工具条 | 高 32px 控件（紧凑），水平间距 `--space-2`，分组间距 `--space-4`；换行时 `row-gap: var(--space-3)` |
| 筛选器数量 | 一行 ≤4 个（认知负荷 ≤4）；更多的收进「更多筛选 ▾」 |
| 搜索框 | 宽度 320px（宽表页 400px），`type="search"`，带清空 `X` 图标（16px） |
| 结果统计条 | 13px `var(--muted)`；有活跃筛选时出现「清除筛选」 |
| 空/零结果 | 严格区分（COMPONENT-SPEC §4.3） |
| 分页 | 每页默认 20（密集表 50）；>100 项走虚拟滚动 |
| 批量操作 | 有选中项时工具条**就地替换**为批量条（不是新开模态） |
| 刷新 | 支持下拉刷新（移动端）；刷新时表格走骨架屏，不整体闪白 |

### 2.3 宽表页加宽

院校库、题库管理使用 `.main-area.is-wide`（1600px）+ `.table.is-dense`（行高 36px）。

## 4. 练习页（刷题 / 背单词 / 记忆卡片 / 错题复盘）

### 4.1 版式：沉浸优先，导航让位

```
┌ 顶栏（同全站，但下滚后自动收缩到 --nav-h-scroll 52px）──┐
┌ 进度条（2px，顶部通栏）──────────────────────────────┐
│  第 12 / 50 题                                        │
└──────────────────────────────────────────────────────┘
┌ 题目区（--container-prose 760px 居中）────────────────┐
│  科目 · 章节 · 难度  [Tag]                            │
│                                                       │
│  题干（16px / 1.7 / --font-serif 长段落）              │
│                                                       │
│  A ○ …   B ○ …   C ○ …   D ○ …                       │
└──────────────────────────────────────────────────────┘
┌ 底部操作条（sticky bottom / 移动端固定底栏）──────────┐
│  [上一题]        [标记模糊] [收藏]      [提交并下一题] │
└──────────────────────────────────────────────────────┘
```

### 4.2 规则

| 项 | 规格 |
|---|---|
| 容器 | `--container-prose` 760px 居中——阅读宽度决定做题专注度 |
| 题干字号 | 16px（比正文大一级），长段落用 `--font-serif`；行高 1.7 |
| 选项 | 单选/多选整行可点，最小高 44px，行间距 `--space-2`，选中态 `background: var(--accent-soft)` + `border-color: var(--accent)` |
| 反馈 | 提交后**立即**给出对错（不延迟到本组结束）：对 → `--success-soft` 底 + `--success-ink` 文案；错 → `--danger-soft` 底 + 正确项高亮 + 「查看解析」 |
| 掌握度标记 | 每题可标「已掌握 / 模糊 / 不会」，用统一四态色（COMPONENT-SPEC §6.2） |
| 键盘 | `1-4` 选选项，`Enter` 提交，`←/→` 上下题，`?` 看快捷键 |
| 无障碍 | 选项用 `role="radio"` + `aria-checked`；反馈用 `aria-live="polite"` 播报 |
| 底部操作条 | 桌面 sticky bottom（`--space-4` 上间距）；移动端固定底栏，按钮高 44px，主操作占 60% 宽度 |
| 中断保护 | 离开页面有未提交作答时，浏览器 `beforeunload` 二次确认；已答进度本地持久化 |

### 4.3 卡片模式（Cards.jsx）

一次一张，`transform` 翻页（不用 `width`/`height` 动画），200ms `--ease-standard`。滑动手势：左滑「不会」、右滑「已掌握」。

### 5.2 分区清单（承接三处迁移）

| Tab | `?tab=` | 内容 | 来源 |
|---|---|---|---|
| 通用 | `general` | 主题（浅/深/跟随系统）、动效（正常/减弱）、初试日期、每日学习时长 | 现有 |
| 备考科目 | `subjects` | 科目增删改、全局科目状态 | **并入** `SubjectManager.jsx` |
| 数据与导入 | `data` | 院校数据导入、文档导入、题库导入 | **并入** `KaoyanImport.jsx` |
| 数据质量 | `quality` | eval_runs 历史、语料体检 | **并入** `QualityDashboard.jsx` |
| 界面自定义 | `ui` | 顶栏项显隐与排序、命令面板快捷键 | 现有 `UiCustomize.jsx` |
| 账号与同步 | `account` | 后端连接状态、同步、AI 服务配置 | 现有 |

### 5.3 规则

| 项 | 规格 |
|---|---|
| 布局 | **严格单列**，`--container-prose` 760px（比常规窄，设置项不该拉长行） |
| 分区间距 | `--space-10` 40px |
| 分区标题 | 16px / `--fw-semibold` / `var(--fg)`；下配 13px `var(--muted)` 一行说明 |
| 设置行 | 最小高 48px，左「名称 + 说明」，右「控件」；行间 `1px solid var(--border-soft)` |
| 控件宽度 | 选择器 240px，开关 44×24px，输入框 280px |
| 危险区 | 放在最底部，用 `--danger-soft` 底的独立卡片，配 `btn--danger` |
| 保存 | 即时保存 + Toast「已保存」；**不做**全页「保存修改」大按钮（易丢失） |
| 删除确认 | 删除科目必须二次确认，并说明影响范围（「该科目下 128 道题、42 篇文档将不再出现在筛选中」） |
| 深链接 | `/settings?tab=subjects` 等必须能直达并高亮对应分区（用于科目管理的重定向落点） |

## 7. 图表页（区域分布 / 学习画像雷达 / 各类统计）

### 7.1 统一规则

| 项 | 规格 |
|---|---|
| 配色 | 一律走 `src/styles/tokens.js` 的 `echartsBaseOption(mode)`，**禁止在页面里写死颜色数组** |
| 主题跟随 | 用 `useDesignTokens()`；主题切换时图表必须重建（不能只在浅色下好看） |
| 标题 | 图表外另给文字结论（「近 30 天正确率从 62% 升到 71%」），不能只给图让用户自己读 |
| 图例 | 必须有；点击图例可切换系列显隐 |
| Tooltip | 圆角 8px、1px 描边、`--shadow-md`（已在 `echartsBaseOption` 内配置） |
| 坐标轴 | 网格线用 `dashed` + `--chart-split-line`；轴标签 12px `--chart-axis` |
| 空数据 | 图表区显示空态（不是空白画布），说明「还没有足够数据」+ 需要多少条 |
| 密度 | 数据点 >200 时采样或聚合；禁止在一张图里堆 >8 个系列 |

### 7.2 迁移提示

现有 `src/components/themeTokens.js`（读 CSSOM 的 hook）与 `src/components/Charts.jsx` 应逐步切到 `src/styles/tokens.js` 的 `useDesignTokens()` / `echartsBaseOption()`，消除两套取色路径。切换期两者值一致，不会闪色。

## 9. 路由切换与状态过渡

| 项 | 规格 |
|---|---|
| 入场 | `opacity 0→1` + `translateY(8px)→0`，`--motion-page` 320ms，`--ease-standard` |
| 顶栏进度 | 懒加载期间顶栏下沿 2px `--accent` 进度条（`--ease-linear`） |
| Suspense 兜底 | 骨架屏（贴近目标页结构），**不用**「加载中…」三个字 |
| 滚动复位 | 路由变化后 `window.scrollTo(0,0)`；从详情页返回列表页时**恢复**原滚动位置 |
| 缓存 | 列表页滚动位置与筛选条件存 sessionStorage，返回时还原 |

## 12. 页面自检清单

- [ ] 使用 `PageShell` / `PageHeader`，无自造容器宽度与标题字号
- [ ] 首屏（仪表盘）展示真实学习内容，无营销式 Hero
- [ ] 每个数据区覆盖 Loading（骨架屏）/ Empty（含引导+操作）/ Error（含重试）/ Populated
- [ ] 无横向滚动（375px 实测）
- [ ] 数字用 `tabular`；无虚构指标
- [ ] 图表配色来自 `echartsBaseOption`，主题切换后重测
- [ ] 长文本有截断/折叠方案（不溢出容器）
- [ ] 键盘可达 + 焦点可见；`prefers-reduced-motion` 下动效收敛
- [ ] 无 emoji、无裸 hex、无紫→粉渐变、无弹跳缓动
